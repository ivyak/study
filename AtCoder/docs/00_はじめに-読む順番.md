# 00. はじめに — 読む順番

この資料群は、**AtCoder の ABC（AtCoder Beginner Contest）で A〜D 問題を安定して解けるように
なる**ための解説です。

> **想定読者**: プログラミングの開発経験はあるが、**競技プログラミング（競プロ）は初めて**。
> A・B は書けば解けるが、C で詰まり D はほぼ手が出ない、という状態から始めます。
> **言語は Python**（AtCoder では PyPy での提出を基本にします）。
>
> **対象日: 2026-09-17 時点。** コンテストの形式・実行時間制限・使える言語のバージョンは
> 運営の告知で変わります。細かい数字は本番前に公式で確認してください。
>
> この資料に既存のリポジトリコードの引用はありません。**貼ってあるコードはすべて
> 書き下ろしのサンプル**で、そのまま提出できる完成形です。読むだけでなく写して動かしてください。

---

## この資料のいちばん大事な主張

A〜D 帯で足りていないのは、発想力ではなく次の 2 つです。

```
  ① 制約を見て「間に合う解法」を書く前に選べること      → 01_2
  ② D 帯の定石（DP・グラフ・数学）を知っていること      → 01_5 / 01_6 / 01_7
```

①が B → C の壁、②が C → D の壁です。どちらも**才能ではなく手順と暗記**でこえられます。

## 読み終わったあとの練習メニュー

読むだけでは身につきません。**詰まってから該当ページに戻る**のがいちばん効率的です。

```
1. AtCoder の過去問（ABC）を 1 回分、時間を計って解く
2. 解けなかった問題の「解説」を読む前に、この資料の §8.7 早見表で引いてみる
3. それでも出てこなければ解説を読む → 該当する分冊を読み直す
4. 同じ種類の問題を 3 問続けて解く（引き出しを固定する）
```

とくに効くのは、**「ABC の C 問題だけを 10 問連続で解く」**ような横断的な練習です。
同じ引き出しを何度も開けることになるので、定着が早くなります。

D 帯まで含めるなら、次の 4 テーマを**それぞれ 5 問ずつ**解くのを目標にしてください。

## 分冊について

1 ファイル 200〜300 行に収まるよう分けています。`01_0` のような `_0` は目次ページです。
`01_1_1`〜`01_1_3`、`01_4_1` / `01_4_2` は、§1 と §4 が長くなったため割ったものです。

**節番号（§1 〜 §8）は分冊をまたいで通し**です。文中で「§4.4 を見てください」と
書いてあるときは `01_4_2` のページを、「§6.3」なら `01_6` のページを開いてください。

### リンクの呼び方（全ページ共通）

どのページでも、リンクの名前は次の 3 通りに統一してあります。

| 形 | 使う場所 | 例 | 指すもの |
|---|---|---|---|
| `01_4_1` | このページのコース表 | `01_4_1` | ファイル 1 本（ID だけ） |
| `§4-1 累積和・ソート・貪欲` | ページ末尾のナビ、「次にどこを読むか」 | `§4-1 …` | ファイル 1 本（名前つき） |
| `§4.4 二分探索` | 本文中の参照 | `§4.4 …` | ページの中の**節 1 つ** |

**ハイフン（`§4-1`）はファイル、ドット（`§4.4`）は節**、と読み分けてください。
`§4-1` と `§4-2` は「§4 を 2 ファイルに割ったうちの何番目か」、
`§4.4` は「§4 の中の 4 番目の節」という意味です。

各ページの末尾には**理解度チェック（3 問）**と「次にどこを読むか」の表があります。
チェックは暗記を問うものではなく、「どこを触ればいいか」「何を知らないとハマるか」を問う形です。
