goal-summary

目標サマリ

Notionの最終目標テーブルと各目標の現状を読み、達成状況を短く整理します。日付付きのMarkdownを保存し、目標タブから履歴を読めるように更新します。

指定Notionの6件の目標を各ページの本文まで確認します。サマリは短い表で整理し、目標一覧の日付をクリックすると読めます。

コマンド一覧構造図詳細な解説

受付可能なコマンド一覧

Codexへの依頼でNotion取得と要約を行います。再生成コマンドだけではNotionを取得しません。

  • $goal-summary 現在の目標達成状況をまとめて

    指定Notionを取得して当日のサマリを保存します。

  • python3 Kyoto_Univ/update_portal.py

    保存済みMarkdownを目標タブへ反映します。

スキルの構造図

決定論：同じ入力に同じ規則を適用LLM：内容の読解・判断・生成

  1. ツール処理

    Notionの一覧と本文を取得

    対象ビューを最後まで読み、各目標のページを確認。

  2. LLM・読解／判断

    現状を短く整理

    条件と現状を比較し、空欄や不明点を区別。

  3. ツール処理

    日付付きMarkdownを保存

    goal_managementに日本時間の当日分を保存。

  4. 決定論・スクリプト

    目標タブを再生成

    Markdownを日付の降順で表示。

Notionにアクセスできる接続が必要です。達成状況の整理は記載内容に基づき、現実の達成を独立に確認するものではありません。

詳細な解説

根拠付きの現状把握

名前・優先度だけでなく、各ページの目標・条件・現状を確認します。数値がなければ達成率を作らず、空欄は未確認とします。

短いサマリと履歴

全体の要約と目標ごとの短い表、根拠リンクを保存します。同日は更新し、過去日のサマリを残します。Notionへの書き戻しや計画の新規作成は対象に含めません。
