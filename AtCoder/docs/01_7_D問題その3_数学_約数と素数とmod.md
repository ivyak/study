## 7.1 約数列挙 — O(√N) の考え方

> N の約数（N を割り切る数）を全部求めよ。制約: N ≤ 10^12

素直に `for i in range(1, N+1)` とすると 10^12 回で当然 TLE。
ここで使うのが **「約数はペアで現れる」**という性質です。

```
   N = 36 の約数

    1 × 36
    2 × 18
    3 × 12
    4 ×  9
    6 ×  6     ← √36 = 6。ここで折り返す
   ─────────
   √N まで調べれば、相方は割り算で出る
```

`i` が約数なら `N // i` も約数。だから **`i` を √N まで調べれば全部見つかります**。

```python
def divisors(n):
    res = []
    i = 1
    while i * i <= n:          # i <= √n
        if n % i == 0:
            res.append(i)
            if i != n // i:    # 平方数のとき重複するので除く
                res.append(n // i)
        i += 1
    return sorted(res)

print(divisors(36))   # [1, 2, 3, 4, 6, 9, 12, 18, 36]
```

計算量は **O(√N)**。N = 10^12 でも 10^6 回で通ります。
`while i * i <= n` と書くのがコツで、`i <= n ** 0.5` は float を経由するので
境界でずれることがあります（→ [§8.4 float の罠](./01_8_Python落とし穴と提出前チェックリスト.md)）。

> **制約に 10^9 や 10^12 が出てきたら、O(√N) を疑う。** §2.4 の逆算表のいちばん下の行です。

### 素因数分解も同じ形

```python
def factorize(n):
    res = []
    i = 2
    while i * i <= n:
        while n % i == 0:
            res.append(i)
            n //= i
        i += 1
    if n > 1:              # 最後に残った n は素数
        res.append(n)
    return res

print(factorize(360))   # [2, 2, 2, 3, 3, 5]
```

最後の `if n > 1` を忘れるのが定番のバグです。
`360 = 2^3 × 3^2 × 5` の `5` は √360 より大きいので、ループでは拾えません。

## 7.2 素数判定とエラトステネスの篩

### 1 個だけ判定するなら O(√N)

```python
def is_prime(n):
    if n < 2:
        return False
    i = 2
    while i * i <= n:
        if n % i == 0:
            return False
        i += 1
    return True
```

### N 以下の素数を全部知りたいなら「篩」

**エラトステネスの篩（ふるい）** は、2 の倍数、3 の倍数、…と消していく方法です。
`O(N log log N)`（実質 O(N)）で、N = 10^6 くらいまで一瞬です。

```
   2  3  4  5  6  7  8  9 10 ...
   ↓
   2 の倍数を消す:  2  3  ✗  5  ✗  7  ✗  9  ✗
   3 の倍数を消す:  2  3  ✗  5  ✗  7  ✗  ✗  ✗
   残ったのが素数:  2  3     5     7
```

```python
def sieve(n):
    is_p = [True] * (n + 1)
    is_p[0] = is_p[1] = False
    i = 2
    while i * i <= n:
        if is_p[i]:
            for j in range(i * i, n + 1, i):   # i*i から始めてよい
                is_p[j] = False
        i += 1
    return [i for i in range(n + 1) if is_p[i]]
```

`range(i * i, ...)` と `i*i` から始めるのは、`i*2` 〜 `i*(i-1)` は
**もっと小さい素数のときにすでに消してある**からです。

## 7.3 GCD と LCM

**GCD（最大公約数）** は標準ライブラリにあります。自分で書く必要はありません。

```python
import math

math.gcd(12, 18)            # 6
math.gcd(12, 18, 24)        # 6（3 個以上も可、Python 3.9+）
math.lcm(4, 6)              # 12（最小公倍数、Python 3.9+）
```

`lcm` が使えない環境向けに、公式も覚えておくと安全です。

```python
def lcm(a, b):
    return a // math.gcd(a, b) * b     # 先に割る（先に掛けると巨大になる）
```

リスト全体の GCD / LCM は `functools.reduce` でまとめます。

```python
from functools import reduce
g = reduce(math.gcd, A)
```

「全部を同じ長さに揃える」「周期が一致するタイミング」は LCM、
「共通の単位に分ける」「比を約分する」は GCD、と対応させて覚えてください。

## 7.4 mod — 「1000000007 で割った余りを出力せよ」

D 帯の数え上げ問題では、答えが天文学的に大きくなるため
**「998244353 で割った余りを出力せよ」**という指定がよく付きます。
使われる値はほぼこの 2 つで、**どちらも素数**です。

```python
MOD = 10 ** 9 + 7        # = 1000000007
MOD = 998244353
```

> **問題文にどちらが書いてあるかを必ず確認してコピペしてください。**
> 取り違えると全ケース WA になり、しかも見た目では気づけません。

### 足し算・引き算・掛け算は「そのつど余りを取る」

```python
ans = (ans + x) % MOD
ans = (ans - x) % MOD       # Python の % は負でも 0 以上を返すので安全
ans = (ans * x) % MOD
```

**Python の `%` は結果が必ず 0 以上**になります（C++ や Java と違う点）。
だから引き算のあとに `if ans < 0: ans += MOD` を書く必要はありません。

### 割り算だけは特別 — 逆元

mod の世界では `/` がそのままでは使えません。代わりに**逆元**を掛けます。
MOD が素数のとき、`a` の逆元は `pow(a, MOD - 2, MOD)` で求まります（フェルマーの小定理）。

```python
# a / b を mod で計算する
ans = a * pow(b, MOD - 2, MOD) % MOD
```

`pow(x, y, m)` は Python の組み込み関数で、**`x^y mod m` を O(log y) で計算**します
（**繰り返し二乗法**が内部で使われています）。`x ** y % m` と書くと
先に巨大な数を作ってしまい TLE / MLE するので、**必ず 3 引数の `pow` を使ってください**。

### 組合せ nCr を mod で求める

```python
MOD = 10 ** 9 + 7
MAXN = 2 * 10 ** 5 + 10

fact = [1] * MAXN                      # 階乗
for i in range(1, MAXN):
    fact[i] = fact[i - 1] * i % MOD

inv_fact = [1] * MAXN                  # 階乗の逆元
inv_fact[MAXN - 1] = pow(fact[MAXN - 1], MOD - 2, MOD)
for i in range(MAXN - 1, 0, -1):
    inv_fact[i - 1] = inv_fact[i] * i % MOD

def comb(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD
```

前処理 O(MAXN)、1 回の `comb` が O(1) です。**このテンプレは丸暗記で貼ってください。**

`if r < 0 or r > n: return 0` のガードが実戦では効きます。
式変形の結果 `r` が範囲外になることがよくあり、これが無いと添字エラーで RE します。

> **mod が要らない小さい場合**は `math.comb(n, r)` で一発です（Python 3.8+）。
> ただし mod 指定がある問題では桁が大きすぎて使えません。

## 7.5 Python は桁あふれしない（が、遅くなる）

C++ では `long long` の範囲（約 9×10^18）を超えると壊れますが、
**Python の `int` は自動で多倍長になるのでオーバーフローしません**。

```python
print(2 ** 200)   # 正しく出る
```

ただし**桁が増えるほど計算が遅くなります**。mod を取らずに巨大な数を掛け続けると、
オーバーフローはしないが TLE します。**mod 指定があるなら、そのつど `% MOD` する**のが鉄則です。

競プロ記事で「オーバーフローに注意」と書いてあるのは C++ の話で、
**Python では読み替えて「桁が伸びて遅くならないか」を気にしてください**。

## 理解度チェック

<details>
<summary><b>Q1.</b> N ≤ 10^12 で「N の約数の個数を求めよ」。どう解く？ 計算量は？</summary>

**A.** `i * i <= N` の範囲で `i` を回し、`N % i == 0` なら `i` と `N // i` の 2 つを数える
（`i * i == N` のときだけ 1 つ）。**O(√N) = 10^6 回**で通る。
約数がペアで現れる性質を使うのがポイント。→ §7.1
</details>

<details>
<summary><b>Q2.</b> `ans = a * b ** (MOD - 2) % MOD` と書いたら TLE / MLE した。なぜ？ 正しくは？</summary>

**A.** `b ** (MOD-2)` が**先に評価されて、10^9 桁級の巨大な整数が作られる**から。
Python はオーバーフローしない代わりにメモリと時間を食い尽くす。
3 引数の `pow(b, MOD - 2, MOD)` を使えば、途中で毎回 mod を取りながら
O(log MOD) で計算される。→ §7.4
</details>

<details>
<summary><b>Q3.</b> 素因数分解のループで `if n > 1: res.append(n)` を書き忘れると、どんな入力で壊れる？</summary>

**A.** **大きい素因数が 1 つ残る入力**、たとえば `n = 14`（= 2 × 7）。
`i` は `i*i <= n` の範囲、つまり 3 までしか回らないので 7 を拾えず、結果が `[2]` になる。
n 自体が素数のとき（`n = 13`）は結果が空になる。→ §7.1
</details>
