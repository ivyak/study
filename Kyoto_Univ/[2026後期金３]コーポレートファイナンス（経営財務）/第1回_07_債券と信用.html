第1回 07｜用語③ 債券・信用

契約で決まる受取額と、市場で変わる価格を区別する。

AIによる講義補足　 /　想起・計算問題 11問　 /　用語編は全5ページ

理系高校生が読めるよう、金融用語は短い定義と参照リンクを添えています。図・数値例・問題はAI作成の学習用です。百分率は小数へ直し、答えの単位も確認してください。用語辞典を引く

債券の言葉｜クーポン・元本・額面・満期

債券は、政府や企業が投資家から資金を借り、将来の支払いを約束する証券です。発行する側を発行体、資金を出す側を債権者といいます。政府の債券が国債、企業の債券が社債です。

用語意味額面100・年利3%・満期3年の例
額面・元本返すお金の基準額。100
クーポンレート額面に対する契約上の利息の率。年3%
クーポンその期間に払う利息の金額。年1回なら毎年3
満期最後の元本返済の時点。3年後
償還元本を返すこと。3年後に100を返す
0年投資家が価格Pを払う
→
1・2年クーポン3ずつ
→
3年クーポン3＋元本100

固定利付債なら契約上のクーポン額は一定です。変動利付債では基準金利などに応じ変わる契約もあります。このページの計算は固定・年1回払い・利払い直後の評価とし、税・手数料を省略します。

ゼロクーポン債は途中の利息が0です。額面より安く買い、満期に額面を受け取れば、クーポンがなくても正の収益率になります。

CALCULATE E16 AI作成・計算問題

額面100万円、年クーポンレート4%、年2回の均等利払いなら、半年ごとのクーポンはいくらですか。

解答・解説を開く

100万円×4%÷2=2万円。年間合計は4万円です。4%を半年ごとに2回払うという意味ではありません。

CALCULATE E17 AI作成・計算問題

額面100のゼロクーポン債を価格95で買い、1年後に100を受け取った。収益率を求めてください。

解答・解説を開く

(100−95)/95≈5.263%。分母は購入価格95であり、額面100ではありません。

参考：米国SEC Investor.gov：債券の支払とリスク

クーポンと満期利回り｜契約と市場価格を分ける

クーポンレートは額面に対する約束です。満期利回り（Yield to Maturity、YTM）は、今払う価格に対して約定CFがどの率で回るかです。価格と全CFの現在価値を一致させる一定率yとして定義します。

P = C/(1+y) + C/(1+y)² + … + (C+FV)/(1+y)T

Cは毎年のクーポン、FVは額面、Tは残り年数です。市場がもっと高い利回りを要求したら、約定CFが同じ債券は安くならないと買ってもらえません。満期利回りが上がると価格は下がります。

関係価格
クーポンレート > YTM額面より高い：プレミアム
クーポンレート = YTM額面と同じ：パー
クーポンレート < YTM額面より低い：ディスカウント

クーポンだけを今の価格で割った率（直接利回り）もありますが、元本償還時の差損益や時間を十分には反映しないため、YTMと区別します。

CALCULATE E18 AI作成・計算問題

額面100、年クーポン3、残存1年。市場が年4%の利回りを要求すると、価格はいくらですか。直接利回りも計算してください。

解答・解説を開く

P=103/1.04≈99.038。直接利回り=3/99.038≈3.029%。YTM4%には、価格99.038から100への元本回収差益も関わります。

RECALL E19 AI作成・理解確認

契約クーポンは変わらないのに、市場金利上昇で債券が下落する理由を説明してください。

解答・解説を開く

同じ将来受取額を、より高い割引率で評価するためです。受取額が固定でも、それを得るために今払ってよい価格は下がります。

AI補足

YTMは約定どおり支払う前提で計算するIRRです。途中売却の収益率は別で、満期までの複利運用成績をYTMと同じにするには途中クーポンを同率で再投資できることも必要です。信用リスクが高い債券では、高いYTMがそのまま期待収益率になるわけではありません。

参考：米国SEC：社債価格・クーポン・利回り

信用スプレッド｜返済の不安などに対応する上乗せ

信用リスクは、元本や利息が契約どおり支払われない可能性です。実際に約束を守れなくなることをデフォルト（債務不履行）といいます。社債の利回りが同通貨・近い満期の基準金利より高ければ、その差を信用スプレッドと呼びます。

信用スプレッド ≈ 社債利回り − 対応する基準金利
例：4.2% − 2.7% = 1.5パーセントポイント = 150bp

bp（basis point、ベーシスポイント）は率の差を表す小さな単位で、1bp=0.01パーセントポイント、100bp=1パーセントポイントです。「スプレッド」は差の幅を意味します。

基準金利時間と通貨・期間の基準
＋
上乗せ幅信用・流動性など
≈
社債利回り約定CFと価格に対応

差の全部が純粋なリスクへの報酬とは限りません。デフォルトによる予想損失や、売りたい時に売りにくい流動性、税や契約条件の違いも含まれ得ます。流動性は現金の多さではなく、ここでは大きな値引きをせず取引できる程度です。比較時は通貨・満期・利息の条件などをそろえます。

投資家はどう見るか

信用分析では、資金繰り、利払い能力、負債額、担保、格付け（返済能力への評価）などと合わせて、上乗せ幅がリスクに見合うかを考えます。格付けは保証ではありません。同じ債券のスプレッドが広がると、他条件一定では要求利回りが上がり価格が下がります。基準金利が下がれば、この作用が相殺される場合もあります。

CALCULATE E20 AI作成・計算問題

基準金利2%、信用スプレッド120bpなら、社債の利回りの目安はいくらですか。

解答・解説を開く

120bp=1.20パーセントポイント。2%+1.2%=3.2%です。120%ではありません。

CALCULATE E21 AI作成・計算問題

基準金利が2.0%から1.5%へ下がり、スプレッドが1.0%から2.0%へ広がった。合計利回りはどう変わりますか。

解答・解説を開く

以前3.0%、以後3.5%。合計では0.5パーセントポイント上がります。CFが同じなら価格は下がる方向です。基準金利の低下だけで判断できません。

CALCULATE E22 AI作成・計算問題

確率95%で約定額110、確率5%で回収40となる1年債がある。期待受取額と、価格100に対する期待収益率を求めてください。約定利回り10%と同じですか。

解答・解説を開く

期待額=0.95×110+0.05×40=106.5。期待収益率=106.5/100−1=6.5%。約定利回り10%とは違い、返済不履行時の損失が反映されています。

AI補足

信用損失を差し引いた期待CFと、約定CFから推計した上乗せ幅を、そのまま二重に組み合わせると損失を二重計上し得ます。このページの価格例は、約定CFとそれに対応する市場利回りの組合せで考えています。

参考：CFA Institute：信用スプレッドには予想信用損失と信用プレミアム等が含まれる

期間ごとの金利｜スポット・フォワード・イールドカーブ

今から1年後の1回払いに対応する年率が1年スポットレートr₁、2年後の1回払いに対応する年率が2年スポットレートr₂です。r₂は2年目だけの金利ではなく、今から2年間に対応する年率です。

PV = CF₁/(1+r₁) + CF₂/(1+r₂)² + …

残り期間を横軸、利回りを縦軸にした曲線をイールドカーブと呼びます。長期ほど高い形が順イールド、逆が逆イールドです。スポットレートを並べる曲線か、利付債のYTMを並べる曲線かも確認します。

フォワードレートは、異なる満期のスポットレートから導く「将来の期間」に対応する率です。複利・信用などの条件をそろえた単純例で、1年後からさらに1年間の率f₁,₂は次式になります。

(1+r₂)² = (1+r₁)(1+f₁,₂)

同じ終点への運用が、今から2年間か、最初の1年＋次の1年かで整合する関係です。フォワードは将来金利予測と関連しますが、リスクへの上乗せなどを含み得るので、そのまま確定的な未来の金利予報ではありません。

CALCULATE E23 AI作成・計算問題

1年スポット2%、2年スポット3%のとき、1年後からの1年フォワードを計算してください。

解答・解説を開く

f=1.03²/1.02−1≈4.0098%。単純な3%−2%=1%ではありません。

CALCULATE E24 AI作成・計算問題

1年後100、2年後100を受け取り、スポット金利がそれぞれ2%、3%。現在価値を求めてください。

解答・解説を開く

100/1.02+100/1.03²≈98.0392+94.2596=192.2988。2年目だけを1.03で一度割るのではありません。

参考：NYU：年次ごとのリスクフリー率

参考：米国SEC：債券・イールドカーブ用語

デュレーションとコンベクシティ｜価格の感応度

利回りが変わったとき価格がどれだけ動くかを考えます。各年のCFの現在価値を価格Pで割った割合をwtとすると、その合計は1です。回収時期tの加重平均がマコーレー・デュレーションDです。

wt = PV(CFt)/P
D = ∑t wt　　修正デュレーション Dm = D/(1+y)
ΔP/P ≈ −Dm Δy

Δは変化量。利回りは小数で入れ、1パーセントポイントならΔy=0.01です。微分した価格の傾きを使う一次近似なので、大きな変動には誤差が出ます。曲がり具合を二階微分で補うものがコンベクシティです。

債券投資家は、金利変動への価格の動きやすさを測る指標として使います。満期までの単なる年数ではなく、途中の受取りも反映します。年1回払いのゼロクーポン債ならD=満期T、Dm=T/(1+y)です。

CALCULATE E25 AI作成・計算問題

修正デュレーション4、利回りが3%から3.5%に上昇。価格の変化率を一次近似で求めてください。

解答・解説を開く

Δy=0.005なので、ΔP/P≈−4×0.005=−0.02、約2%下落です。3.5−3=0.5をそのまま入れてはいけません。

CALCULATE E26 AI作成・計算問題

5年ゼロクーポン債の利回りが5%。DとDₘを計算してください。

解答・解説を開く

D=5年、Dₘ=5/1.05≈4.7619。満期前に回収がないので、重みは5年目に100%集まります。
