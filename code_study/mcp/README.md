# MCP（Model Context Protocol）やさしい解説シリーズ

### 「MS365にMCPサーバーが追加されたから、TeamsのリンクをClaudeに貼るだけで内容を見てくれる」を、論理的に理解するためのノート

---

## まず、結論の3行

きっかけは先輩から聞いたこの話です。

> **「MS365にMCPサーバーが追加されたから、TeamsのリンクをClaudeに貼るだけで内容を見てくれるらしい」**

この話の正体は、3行にするとこうです。

```
① MCP ＝ AIと外のデータをつなぐ「共通の差込口」の規格（USB-Cみたいなもの）
② Microsoft 365 用のその差込口（MCPサーバー）ができたので、Claudeが
   Teams・Outlook・SharePoint・OneDrive に手を伸ばせるようになった
③ ただし手が届くのは「あなた自身が見られる範囲」だけ。鍵（権限）は
   あなたのものを借りているから
```

つまり、**AIが賢くなったのではなく、AIの「手が届く範囲」が広がった**という話です。

そして最後の③がいちばん大事です。ここを理解すると「なんで他人のチャットは読めないの？」「情報漏れないの？」が自分で説明できるようになります。

## この資料の方針

- **中学生でもわかる言葉**で書く。専門用語は初めて出てきたときに必ず「＝〜」で言い換える
- **図を惜しまない**。文章で3行かかることは、図なら3秒で分かる
- **たとえは使い回す**。シリーズ全体で同じたとえを使うので、途中で混乱しません

| たとえ | 何のこと |
|---|---|
| 電話しか使えない名探偵 | AI（すごく知識があるが、現場には行けない） |
| USB-C（共通の差込口） | MCP |
| お客さん / ウェイター / 厨房 | MCP Host / MCP Client / MCP Server |
| あなたの名前で入れる入館証 | アクセストークン（認証の鍵） |

- **断定できないことは断定しない**。公式ドキュメントに書いてあることと、自分の推測は分けて書く
