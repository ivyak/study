べき乗法のしくみ

第4回｜固有方向への分解と式の導出

講義を通して言いたいこと

想定読了時間 約16分

べき乗法は、同じ行列を繰り返し掛けると、絶対値が最大の固有値に対応する方向が目立つようになることを利用する。鍵になる式 \(A^k x=V\Lambda^k c\) は、固有ベクトルを列に並べた等式 \(AV=V\Lambda\) を繰り返して得られる。課題4で固有ベクトルの誤差を比べるときは、基準ベクトルと近似ベクトルの長さと位相をそろえる。

固有値からべき乗法へ

想定読了時間 約6分

解説 1｜なぜ \(A^k x=V\Lambda^k c\) なのか

想定読了時間 約6分

各固有方向は、\(A\) を一度掛けるたびに、それぞれの固有値の倍率で伸び縮みする。

そもそも固有値とは

行列 \(A\) をベクトルに掛けると、普通は向きも長さも変わる。しかし、あるゼロでないベクトル \(v\) は掛けても同じ直線上にとどまり、倍率だけが変わる。このとき \(v\) を固有ベクトル、倍率 \(\lambda\) を固有値と呼び、\(Av=\lambda v\) と書く。倍率が負なら向きは反転し、複素数なら位相も変わる。

べき乗法とは

最初のベクトル \(x\) に同じ行列を何度も掛ける。並びは \(x,Ax,A^2x,A^3x,\ldots\)。各固有方向の成分は、掛けるたびに対応する固有値の倍率で変わる。たとえば \(A=\begin{pmatrix}3&0\\0&1\end{pmatrix}\)、\(x=(1,1)^{\mathsf T}\) なら、\(A^kx=(3^k,1)^{\mathsf T}\)。\(k\) を増やすと、第1成分が第2成分より大きくなり、ベクトルの方向は第1固有ベクトルへ近づく。

数値を大きくしすぎないため、実際には \(y_k=Ax_k\) を計算するたびに長さを1にそろえる。\(y_k\ne0\) のとき、反復は次の形になる。

\[x_{k+1}=\frac{Ax_k}{\|Ax_k\|}.\]

この操作は長さだけを変えるので、繰り返し掛けて現れる固有方向の優劣は変わらない。教材はこの後、固有値の推定と収束判定も示している。ここでは方向が選ばれる理由に集中する。

最初のベクトルを固有方向へ分ける

教材の p.23 の式(2.9) では、固有ベクトル \(v_1,\ldots,v_n\) を列に並べて \(V=(v_1,\ldots,v_n)\)、固有値を対角に並べて \(\Lambda=\begin{pmatrix}\lambda_1&&0\\&\ddots&\\0&&\lambda_n\end{pmatrix}\) とする。第 \(i\) 列どうしで \(Av_i=\lambda_i v_i\) が成り立つため、列をまとめれば

\[AV=(Av_1,\ldots,Av_n)=(\lambda_1v_1,\ldots,\lambda_nv_n)=V\Lambda.\tag{2.9}\]

教材は \(|\lambda_1|>|\lambda_2|>\cdots>|\lambda_n|>0\) を仮定する。固有値がすべて異なるので固有ベクトルは一次独立で、\(V\) は逆行列を持つ。だから任意の \(x\in\mathbb C^n\) を \(x=Vc=c_1v_1+\cdots+c_nv_n\) と一意に表せる。\(c_i\) は、最初の \(x\) に第 \(i\) 固有方向がどれだけ含まれるかを表す係数である。

質問の式を一行ずつ導く

まず式(2.9)の両辺へ左から \(A\) を掛ける。行列の掛け算では \(A(AV)=(AA)V\) と括弧を移せるため、

\[A^2V=A(AV)=A(V\Lambda)=(AV)\Lambda=(V\Lambda)\Lambda=V\Lambda^2.\]

もう一度同じ操作をすれば \(A^3V=V\Lambda^3\)。これを \(k\) 回繰り返すと \(A^kV=V\Lambda^k\) となる。そこで \(x=Vc\) を代入する。ここが p.24 の等式の最初の部分である。

\[A^kx=A^k(Vc)=(A^kV)c=\boxed{V\Lambda^kc}.\]

つまり \(A^k\) を一般のベクトルに直接掛ける代わりに、固有ベクトルで表した係数 \(c\) を先に考えている。\(\Lambda\) は対角行列なので、\(\Lambda^kc=(\lambda_1^kc_1,\ldots,\lambda_n^kc_n)^{\mathsf T}\)。最後に \(V\) を掛ければ、それぞれの係数に対応する固有ベクトルを掛けて足すことになる。

\[V\Lambda^kc=\sum_{i=1}^n c_i\lambda_i^k v_i =\lambda_1^k\left(c_1v_1+\sum_{i=2}^n c_i\left(\frac{\lambda_i}{\lambda_1}\right)^k v_i\right).\]

なぜ第1固有方向が残るのか

教材の仮定では \(i\ge2\) に対して \(|\lambda_i/\lambda_1|<1\)。だから \((\lambda_i/\lambda_1)^k\) は \(k\to\infty\) で0に近づく。括弧の中では他の固有方向が小さくなり、\(c_1\ne0\) なら \(c_1v_1\) が残る。これが「第1固有ベクトルの成分が支配的になる」の正確な意味である。

\(c_1=0\) なら最初から第1固有方向が含まれず、この説明ではそこへ近づかない。また、正規化後のベクトルそのものは \(\lambda_1<0\) なら符号が交互に変わり、複素固有値なら位相が回ることがある。「近づく」のは符号や位相を同一視した方向である。

数値的な手順を具体例で追う

想定読了時間 約5〜6分

解説 2｜反復で固有ベクトルが見えてくる

想定読了時間 約5〜6分

毎回の正規化は長さを抑えるだけで、固有ベクトルへ近づく向きはそのまま残る。

画像の \(x_k=(x_{k;i})_i\) は「\(k\) 回目のベクトル \(x_k\) は、成分 \(x_{k;1},x_{k;2},\ldots\) を並べたもの」という意味。\(k\) は反復回数、\(i\) はその中の成分番号で、セミコロンは二つの番号を区切っている。2成分なら \(x_k=(x_{k;1},x_{k;2})^{\mathsf T}\)。同様に \(y_k=(y_{k;i})_i\) と書き、\(y_{k;i}\) は \(y_k\) の第 \(i\) 成分を表す。たとえば下の例の \(x_0=(1,0)^{\mathsf T}\) では \(x_{0;1}=1\)、\(x_{0;2}=0\) である。

初期ベクトル \(x_0\) の条件

\(x_0\) はゼロベクトル以外を選ぶ。さらに、第1固有ベクトル \(v_1\) を含むように、固有ベクトルで分けたときの \(x_0=c_1v_1+\cdots+c_nv_n\) で \(c_1\ne0\) が必要である。もし \(c_1=0\) なら、何回 \(A\) を掛けても最初になかった \(v_1\) 成分は生まれない。最初から長さ1である必要はなく、最初の反復で正規化できる。\(v_1\) が未知なら、実際にはゼロでないランダムなベクトルなどから始める。

対角行列ではない例として、\(A=\begin{pmatrix}2&1\\1&2\end{pmatrix}\)、初期ベクトルを \(x_0=\begin{pmatrix}1\\0\end{pmatrix}\) とする。この行列には \(v_1=(1,1)^{\mathsf T}\)、\(v_2=(1,-1)^{\mathsf T}\) という二つの固有ベクトルがあり、実際に掛けると \(Av_1=3v_1\)、\(Av_2=v_2\) となる。絶対値が最大の固有値は \(3\) で、目標は \(v_1\) の方向である。

この例の \(x_0=(1,0)^{\mathsf T}\) は \(\tfrac12v_1+\tfrac12v_2\) なので条件を満たす。一方、\(x_0=(1,-1)^{\mathsf T}=v_2\) を選ぶと、\(Av_2=v_2\) のため反復しても \(v_2\) の方向のままで、\(v_1\) は得られない。なお、教材の成分比 \(\mu_k=y_{k;i}/x_{k;i}\) を求める際は、割る成分 \(x_{k;i}\ne0\) を選ぶ。小さすぎる成分で割ると誤差が大きくなりやすいので、絶対値が大きい成分を選ぶとよい。

画像の手順どおり、まず \(y_0=Ax_0=(2,1)^{\mathsf T}\) を計算する。第1成分が \(x_{0;1}=1\ne0\) なので、固有値の推定値は \(\mu_0=y_{0;1}/x_{0;1}=2\)。次に \(x_1=y_0/\|y_0\|=(2,1)^{\mathsf T}/\sqrt5\) と正規化する。\(\mu_0=2\) はまだ真の固有値 \(3\) ではないが、反復を続けると近づく。

各回で同じく \(y_k=Ax_k\) を求め、第1成分の比 \(\mu_k=y_{k;1}/x_{k;1}\) を計算してから、\(x_{k+1}=y_k/\|y_k\|\) とする。この例では第1成分は常にゼロでない。はじめの数回は次のようになる。

\(k\)正規化した \(x_k\)掛けた結果 \(y_k=Ax_k\)成分比 \(\mu_k\)
0\((1,0)^{\mathsf T}\)\((2,1)^{\mathsf T}\)\(2\)
1\((2,1)^{\mathsf T}/\sqrt5\)\((5,4)^{\mathsf T}/\sqrt5\)\(5/2=2.5\)
2\((5,4)^{\mathsf T}/\sqrt{41}\)\((14,13)^{\mathsf T}/\sqrt{41}\)\(14/5=2.8\)
3\((14,13)^{\mathsf T}/\sqrt{365}\)\((41,40)^{\mathsf T}/\sqrt{365}\)\(41/14\approx2.93\)

なぜ \(x_k\) が \(v_1\) の方向へ近づくのか。最初の \(x_0\) は \(\tfrac12(1,1)^{\mathsf T}+\tfrac12(1,-1)^{\mathsf T}\) と分けられる。前者には毎回 \(3\)、後者には毎回 \(1\) が掛かるので、正規化する前は

\[A^kx_0=\frac{3^k}{2}\begin{pmatrix}1\\1\end{pmatrix}+\frac12\begin{pmatrix}1\\-1\end{pmatrix}=\frac12\begin{pmatrix}3^k+1\\3^k-1\end{pmatrix}.\]

二つの成分の差はいつも \(1\) だが、成分の大きさは \(3^k\) とともに増える。したがって差は相対的に小さくなり、正規化した \(x_k\) は \((1,1)^{\mathsf T}/\sqrt2\) に近づく。表でも成分比は \(2:1\)、\(5:4\)、\(14:13\) と \(1:1\) に近づいている。

固有ベクトルに十分近づくと \(y_k=Ax_k\approx3x_k\) なので、ゼロでない第1成分の比も \(\mu_k\approx3\) になる。画像の手順ではこの \(\mu_k\) の変化が小さくなったら止め、最後の \(x_k\) を第1固有ベクトルの近似として採用する。実際の計算では、停止時に \(\|Ax_k-\mu_kx_k\|\) も小さいか確かめると、固有方程式を満たしているか確認できる。

課題4｜固有ベクトルの相対誤差

想定読了時間 約4分

解説 3｜基準ベクトルを求め、長さと位相をそろえる

想定読了時間 約4分

固有ベクトルは何倍しても同じ固有方向を表す。比較前に倍率と符号・位相を決めてから、式(2.11)を計算する。

「真の固有ベクトル」はどう用意するか

厳密な \(v_i\) を手計算で得られる行列なら、\(\det(A-\lambda I)=0\) から \(\lambda_i\) を求め、\((A-\lambda_i I)v_i=0\) の非零解を取る。しかし課題4のランダム行列では、厳密な固有ベクトルを通常は求めない。np.linalg.eig(A) で得た数値解を比較用の基準ベクトルとする。これは数学的な真値ではないので、得られる値は厳密な真値との誤差ではなく、数値基準との相対差である。

np.linalg.eig(A) は固有値の配列 values と、固有ベクトルを列に並べた行列 vectors を返す。べき乗法の結果 \(\tilde v_1\) は絶対値最大の固有値に対応するため、i = np.argmax(np.abs(values)) として vectors[:, i] を取る。vectors[i, :] は行なので違う。一般の第 \(i\) 固有ベクトルを比べる場合も、配列の番号をそのまま信じず、対応する固有値を照合する。

条件(1)(2)を満たす正規化

ここでは既存の誤差・残差関数と同じ最大値ノルム \(\|z\|_\infty=\max_j|z_j|\) を使い、両方をそれぞれのノルムで割る。すると \(\|v_1\|_\infty=\|\tilde v_1\|_\infty=1\) となり、条件(1)を満たす。片方だけを正規化しても条件(1)は保証されない。

次に、両方でゼロでない成分番号 \(k\) を一つ選ぶ。実数ベクトルなら、それぞれ第 \(k\) 成分が負のときベクトル全体に \(-1\) を掛ければよい。複素数にも通用する書き方は \(z\leftarrow z\,\overline{z_k}/|z_k|\)。この単位複素数を掛けると第 \(k\) 成分は \(|z_k|>0\) となり、ノルムも変わらない。\(v_1\) と \(\tilde v_1\) のそれぞれに行う。\(k\) は両方で成分の絶対値が十分大きい位置を選ぶと、丸め誤差に強い。

\[\frac{\|v_1-\tilde v_1\|_\infty}{\|v_1\|_\infty}=\|v_1-\tilde v_1\|_\infty\qquad(\text{両方の最大値ノルムを1にした場合}).\]

たとえば基準が \((1,1)^{\mathsf T}\)、近似が \((-1,-0.75)^{\mathsf T}\) なら、\(k=1\) で後者を全体ごと反転して \((1,0.75)^{\mathsf T}\) にする。両方の最大値ノルムは1なので、相対誤差は \(\max(0,0.25)=0.25\)。反転前のまま引くと、固有方向の違いではなく符号の違いを数えてしまう。

課題4の実装例

import numpy as np

def dominant_eigenvector_error(A, eigenvector):
    values, vectors = np.linalg.eig(np.asarray(A, dtype=float))
    i = np.argmax(np.abs(values))  # べき乗法が狙う固有値
    v_ref = vectors[:, i].astype(complex)
    v_num = np.asarray(eigenvector, dtype=complex)
    if np.linalg.norm(v_num, ord=np.inf) == 0:
        raise ValueError("近似固有ベクトルがゼロです")

    # 条件(1): 両方の最大値ノルムを1にする
    v_ref /= np.linalg.norm(v_ref, ord=np.inf)
    v_num /= np.linalg.norm(v_num, ord=np.inf)

    # 条件(2): 両方で十分大きい共通成分を選び、正実数にする
    k = np.argmax(np.minimum(np.abs(v_ref), np.abs(v_num)))
    if abs(v_ref[k]) == 0 or abs(v_num[k]) == 0:
        raise ValueError("共通の非零成分がありません")
    v_ref *= np.conj(v_ref[k]) / abs(v_ref[k])
    v_num *= np.conj(v_num[k]) / abs(v_num[k])

    return np.linalg.norm(v_ref - v_num, ord=np.inf)

# 課題4の各試行で: eigenvector は power_method(A) の戻り値
eigenvectors_errors.append(dominant_eigenvector_error(A, eigenvector))

この関数はべき乗法が最大絶対値の単純な固有値に対応する方向へ収束した場合の比較用。近い大きさの固有値や重複固有値があると、列の対応や「1本の真の固有ベクトル」との比較自体に注意が要る。既存の kadai4_1.py では、連立方程式用の np.linalg.solve(A, b) や未定義の b・x が残っているため、固有値の基準値にも np.linalg.eig(A) を使って各誤差を計算する。
