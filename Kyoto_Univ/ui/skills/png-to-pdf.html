png-to-pdf

PNGフォルダをPDF化

指定フォルダのPNGをファイル名順に並べ、1画像1ページのPDFにまとめます。スクリーンショットや板書画像をまとめて読むときに使います。

入力はPNGの入ったフォルダのパスです。「PDF名は○○」と指定すれば、入力フォルダ内に○○.pdfとして保存します。名前の昇順をページ順として使い、変換後は画像数とPDFへのリンクを返します。

コマンド一覧構造図詳細な解説

受付可能なコマンド一覧

入力フォルダに加え、PDF名や保存先を指定できます。CLIの--nameは入力フォルダ内のPDF名、-oは出力パスです。同時指定はできません。--overwriteは明示的な上書き指定です。

  • $png-to-pdf 「フォルダのパス」をPDFにして

    フォルダ直下のPNGを名前順にまとめ、フォルダ内のoutput.pdfに保存します。

  • $png-to-pdf 「フォルダのパス」 PDF名は「公共政策論II 第3回」

    入力フォルダ内に公共政策論II 第3回.pdfとして保存します。拡張子は省略できます。

  • $png-to-pdf 「フォルダのパス」を「保存先のパス.pdf」にまとめて

    入力フォルダと出力PDFのパスを指定します。

  • .venv/bin/python utils/screenshot/png_to_pdf.py "入力フォルダ" --name "公共政策論II 第3回"

    入力フォルダ内に指定した名前でPDFを保存します。

  • .venv/bin/python utils/screenshot/png_to_pdf.py "入力フォルダ" -o "出力.pdf"

    リポジトリルートから既存スクリプトを直接実行する場合の例です。

詳細な解説

対象と並び順

フォルダ直下の.pngや.PNGを対象にします。サブフォルダは走査しません。Pythonのsortedによる名前順なので、1.png、10.png、2.pngの順になります。

PDFのページ構成

先頭から名前順に1画像1ページでまとめます。複数画像を縦長の1ページに貼り合わせる処理ではありません。元のPNGは保存します。

保存先と既存ファイル

名前だけを指定したら入力フォルダ内に保存し、.pdfがなければ付けます。未指定ならoutput.pdfです。スキルでは既存なら指定名_2.pdfなどを選び、実際の保存名を報告します。CLI自体は既存出力をエラーにし、--overwriteを指定した場合に上書きします。

実行環境とエラー

リポジトリの仮想環境を使います。依存はimg2pdfとPillowです。フォルダ不在、PNGが0枚、壊れた画像等で失敗した場合は、原因を伝えます。
