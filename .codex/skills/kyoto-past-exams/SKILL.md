# 京大過去問検索

検索を始める前に、教科名・**ファイル名に使われる教員名の表記**・履修年度を確認する。「前年度」は履修年度−1。教員名が入力されていなければ検索を実行せず、入力を求める。ファイル一覧や過去の結果から教員名を推測・確定しない。これはファイル名上の表記比較であり、実在の同一人物の同定ではない。

## 手順

1. `scripts/search.py collect` で京大wiki、KUInfo2020、KU1025、過去問Driveを順に走査し、一覧・未巡回・取得失敗を保存する。1ソースで発見しても残りを省略しない。取得方法は [references/sources.md](references/sources.md)。
2. `search` で保存一覧の**ファイル名だけ**から教科・教員・年度を照合する。フォルダ名や本文、更新日時でこの判定を補わない。ファイル名の教科番号、A/B、1/2、学期を保つ。正規化はNFKC・空白除去・大小文字統一。同じ名前という文字列の判定であり、実在の同一人物の同定は行わない。
3. Driveのプレビューで内容を読み、資料の種類を「問題」「講義資料」「解答」「演習問題」のバッジに分類する。複数種類が同居すれば複数バッジ。試験問題は「問題」、授業の練習・課題は「演習問題」。ファイル名だけで種類を確定せず、読めない・未読の資料には「未確認」を付ける。
4. 結果を既存の過去問一覧に差分統合する。なければ `study/past_exam_search.md` と検索JSONを保存。資料自体はダウンロード・ローカル保存しない。Driveの閲覧リンクを残す。ブラウザのプレビューに必要な通信は行ってよい。プレビュー不能の場合は未確認とし、ダウンロードで迂回しない。

```bash
python3 <skill-dir>/scripts/search.py collect --course '工業数学A1' --teacher '柴山' --out /tmp/exams.json
python3 <skill-dir>/scripts/search.py collect --course '工業数学A1' --teacher '柴山' --out /tmp/exams.json --resume
python3 <skill-dir>/scripts/search.py search --index /tmp/exams.json --course '工業数学A1' --teacher '柴山' --academic-year 2026
```

collectは1回につき各ソース最大200ページ。未巡回が残れば再開し、取得済みページや未巡回の消化に進展がなくなれば終了してURLを未走査欄に残す。無限に再試行しない。`--resume` は取得済みページを更新しない。最新確認は新規collect。別名は裏付けのあるものだけ `--alias` を両コマンドに同じ形で指定する。

## ファイル名の判定：次の3条件のみ

- 同名教科・同名教員・前年度
- 同名教科・同名教員・前年度よりも前
- 同名教科・違う名前の教員（年度は問わない）

「あり」は該当ファイル名があれば付ける。資料の種類が講義資料や解答でも、この**ファイル名の存在判定**から除外しない。年度の指定がない資料を前年度・それ以前の枠へ推測して入れない。姓とフルネームを勝手に同一表記に変換しない。ファイル名から教員・年度を読み取れない場合は未確認とする。教員名が未入力の場合は検索を開始せず、既存の候補を使った条件判定もしない。

未発見は「確認範囲では見つからず」で、未走査・取得失敗・一覧全件取得未確認がある場合は該当する未発見判定を未確認とする。確認済みの一致があれば、他の領域が未走査でも「あり」とできる。同じDrive IDを1件にまとめ、全掲載元を管理記録に残す。URLが異なっても同じIDなら重複表示しない。

## 出力

3条件の判定は短く示す。資料の一覧は **「タイトル名」「資料の種類（バッジ）」「URL」だけ**。タイトル名にはファイル名を使う。詳細な根拠、取得日時や掲載元は管理JSONに残し、一覧に列を増やさない。URLはDriveの閲覧リンクで、ダウンロードリンクや保存ファイルのパスは表示しない。

**一番下**に「走査できなかった領域」をまとめ、Drive上の階層パス、理由、閲覧URLを示す。あるフォルダの直下を走査できていない場合は、そのフォルダを1件だけ表示し、配下の項目を重ねて列挙しない。未巡回、取得失敗、プレビュー不能、Driveの全件取得を確認できない入口を区別して短く添える。未走査を「なし」と表現しない。既存のダウンロード済み資料は削除しないが、新しい処理は配置確認やダウンロードを行わない。
