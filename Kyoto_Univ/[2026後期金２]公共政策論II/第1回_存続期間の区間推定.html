SECTION 01何を推定するのか：経過年数と総存続期間

講義写真 · p.42

ベルリンの壁が1961年にでき、1969年に訪れたとします。訪問時点では「すでに8年続いている」ことは分かりますが、壁が最終的に何年間存続するかは分かりません。講義ではこの未知の総存続期間を θ（シータ）とし、観測済みの8年から θ を推定します。

1961年壁の成立
経過時間 0
→
1969年訪問・観測
X = 8 年
→
1961 + θ 年壁の終わり
まだ分からない
記号意味この例
θ成立から終わりまでの総存続期間（未知のパラメータ）推定したい年数
X成立から訪問までの経過年数（確率変数）観測前はランダム
xX の観測値・実現値1969 − 1961 = 8 年
θ − x訪問後に残っている期間θ − 8 年

θ は壁の寿命全体、θ − 8 は訪問時点からの残り寿命です。この区別を最初に押さえると、最後に「8を引く」理由が分かります。

提供資料は写真2枚に写ったp.42〜47です。以下はその範囲の解説で、第1回のそれ以前の内容は未確認です。年数は講義と同じく年単位で簡略化しています。

SECTION 02出発点は「訪問時点が一様」という仮定

講義写真 · p.42–43

壁が存在している間に訪れたので、必ず 0 ≤ X ≤ θ です。これが p.42 の Pr(0 ≤ X ≤ θ) = 1 の意味です。ただし、この条件だけでは区間推定の計算はできません。

p.43 ではさらに、「訪問は壁の存続期間内の特別でない時点に起こる」と考え、同じ長さの時間帯なら訪問する確率も等しいと仮定します。数式では、θ を固定したとき X が 0〜θ の一様分布に従うというモデルです。

X ∼ Uniform(0, θ)
Pr(a ≤ X ≤ b) = (b − a) / θ　（0 ≤ a ≤ b ≤ θ）

例えば、総存続期間の最初の4分の1に訪問する確率は25%、中央の半分に訪問する確率は50%になります。連続分布では一点だけの確率は0なので、ここでは端点の「≤」と「<」の違いは結果に影響しません。

AI補足・仮定の確認

「いつ訪れるか分からない」ことから、一様分布が自動的に導かれるわけではありません。観光の人気や出来事によって訪問時期が偏れば、このモデルは崩れます。以下の信頼水準は、この仮定が成り立つ場合の値です。

SECTION 03中央50%に入る、という出来事を書く

講義写真 · p.44

中央50%を残すには、存続期間の最初と最後から25%ずつを除きます。残る区間は θ/4 から 3θ/4 までで、長さは θ/2 です。

除く 25%残す 50%除く 25%
0θ/43θ/4θ
Pr(θ/4 ≤ X ≤ 3θ/4) = (3θ/4 − θ/4) / θ = 0.5

この段階の区間は「X がどこに入るか」を表しています。しかし知りたいのは θ の方です。そこで同じ不等式を、θ が真ん中に来る形に変えます。

SECTION 04不等式を反転して、θの区間を求める

講義写真 · p.45

2つの不等式を別々に解き、最後に合わせます。割る数は正なので、不等号の向きは変わりません。

θ/4 ≤ X　⇒　θ ≤ 4X
X ≤ 3θ/4　⇒　4X/3 ≤ θ
したがって　4X/3 ≤ θ ≤ 4X

よって Pr(4X/3 ≤ θ ≤ 4X) = 0.5 です。観測値 x = 8 を代入すると、総存続期間の50%信頼区間が得られます。

θ の区間：[4 × 8 / 3, 4 × 8] = [32/3, 32] 年
約 10.67 ～ 32 年

すでに経過した8年を両端から引けば、1969年からの残り期間の区間になります。

θ − 8 の区間：[32/3 − 8, 32 − 8]
= [8/3, 24] 年 = 2年8か月 ～ 24年

終了する暦年で表すなら、総存続期間には1961年を足し、残り期間には1969年を足します。どちらも、講義の年単位の扱いでは約1971.67〜1993年となり、同じ結果です。

CHECK 01 AI作成・計算確認

経過年数が8年のとき、総存続期間と残り期間の50%区間を、何も見ずに求めてください。

解答・途中式を開く

総存続期間は [4x/3, 4x] = [32/3, 32] 年。残り期間は [x/3, 3x] = [8/3, 24] 年です。

8/3年 = 2 + 2/3年。1年は12か月なので、2/3 × 12 = 8か月です。下限は「2年8か月」であり「2年6.7か月」ではありません。

SECTION 05区間推定・点推定と「50%」の読み方

講義写真 · p.46

未知の θ を幅のある区間で求めるのが区間推定（interval estimation）、一つの数で求めるのが点推定（point estimation）です。p.46 は今回の区間を「50%信頼区間」と呼んでいます。1969年時点では θ の終わりが未来にあるため、この推定が将来予測にもつながります。

講義は点推定の例として区間の中央を挙げています。今回の総存続期間の中央は、次の値です。

(32/3 + 32) / 2 = 64/3 ≈ 21.33 年
対応する残り期間：64/3 − 8 = 40/3 ≈ 13.33 年

p.46 の「21.3年」は総存続期間の値です。残り期間の値ではありません。また、区間の中央を選ぶのは点推定の一例で、それだけで最良の推定値や期待値だと証明されたわけではありません。

AI補足・信頼区間の厳密な意味

頻度論では θ は固定された未知の値で、ランダムなのは X と、X から作る区間 [4X/3, 4X] です。同じ θ の下で訪問時点を一様に繰り返し選び、その都度区間を作ると、その50%が真の θ を含みます。

観測後の固定区間 [32/3, 32] について、「θ が50%の確率でここにある」という事後確率を、そのまま主張するものではありません。θ 自体に確率を与えるには別途モデルが必要です。p.45 の吹き出しは、この区間を作る手続きの被覆率として読むと正確です。

CHECK 02 AI作成・計算確認

経過年数が12年なら、50%区間と、区間の中央による点推定を求めてください。

解答・途中式を開く

総存続期間：[4 × 12/3, 4 × 12] = [16, 48] 年。残り期間：[16 − 12, 48 − 12] = [4, 36] 年。

総存続期間の点推定は (16 + 48)/2 = 32年。対応する残り期間は 32 − 12 = 20年です。

SECTION 06講義の結末と、この推定が依存するもの

講義写真 · p.47

p.47 は、この計算による予測が訪問時点から「2年8か月後〜24年後」であり、壁の崩壊が予測から約20年後だったと説明しています。講義の年単位の比較では、結果はこの50%区間に入っています。

また、考案者として Richard Gott を紹介し、訪問時点を特別扱いしない発想を「コペルニクスの原理」と結び付けています。ここでの統計的な要点は、その発想を一様分布という具体的な仮定に置き換えていることです。

AI補足・結果の評価

この一例が区間に入ったことだけで、一様分布の仮定や予測方法全体の正しさを確認できるわけではありません。仮定の下でも50%区間は半分の確率で外れます。また、経過年数以外の政治的・社会的情報は、この計算には入っていません。

SECTION 07計算確認：信頼水準を変えるとどうなるか

AI補足・p.44〜45の計算を一般化／以下の確認問題はAI作成

同じ考え方で中央の割合を c（0 < c < 1）とし、両端から a = (1 − c)/2 ずつ除きます。例えば c = 0.95 なら a = 0.025 です。

Pr(aθ ≤ X ≤ (1 − a)θ) = c
⇒　X/(1 − a) ≤ θ ≤ X/a
観測後の総存続期間：[x/(1 − a), x/a]
残り期間：[ax/(1 − a), (1 − a)x/a]

信頼水準を上げると両端から除く部分が小さくなり、θ の区間は広がります。より多くの場合に真値を含めるため、予測の幅を大きくするという関係です。

CHECK 03 AI作成・計算確認

経過8年のとき、中央95%を使った総存続期間と残り期間の区間は？

解答・途中式を開く

a = (1 − 0.95)/2 = 0.025。総存続期間は [8/0.975, 8/0.025] = [約8.21, 320] 年。

残り期間は [8/0.975 − 8, 320 − 8] = [約0.21, 312] 年。下限の正確な値は8/39年（約2.46か月）です。50%区間 [約2.67, 24] 年より広くなります。

CHECK 04 AI作成・計算確認

経過10年、中央80%の場合、両端に除く割合と残り期間の区間を求めてください。

解答・途中式を開く

a = (1 − 0.8)/2 = 0.1 なので、除くのは両端に各10%です。各20%ではありません。

総存続期間は [10/0.9, 10/0.1] = [100/9, 100] 年。残り期間は [100/9 − 10, 100 − 10] = [10/9, 90] 年 ≈ [1.11, 90] 年です。

CHECK 05 AI作成・計算確認

総存続期間が実際には24年だったと仮定します。どの訪問時点Xなら、作った50%区間が真の24年を含みますか？

解答・途中式を開く

区間が24年を含む条件は 4X/3 ≤ 24 ≤ 4X。左側から X ≤ 18、右側から X ≥ 6 なので、6 ≤ X ≤ 18 です。

X は0〜24の一様分布だから、確率は (18 − 6)/24 = 0.5。これが「区間を作る手続きの50%が真値を含む」という意味を直接確かめる計算です。
