Git を .git から読む

「コマンドの使い方」ではなく、「そのコマンドが .git のどのファイルを書き換えたか」を追う解説資料。

git 2.50.1 / macOS対象日 2026-09-17出力はすべて実物

Git のコマンドがやることは、この 2 つだけ

その 1.git/objects/ に「中身」を書き足す

不変・追記のみ。blob / tree / commit / tag の 4 種類

その 2.git/refs/ や .git/HEAD の「文字列」を書き換える

ブランチや現在地を指す、数十バイトのテキスト

merge も rebase も pull も、この組み合わせです。.git の中の数個のテキストファイルが読めれば、Git の挙動はほぼ説明がつきます。
