# Recall Quiz

講義で習った知識や解法を、短い1問1答で思い出すクイズです。GitHub Pagesで公開し、ブラウザのJavaScriptだけで動きます。ログインやバックエンドは使いません。

標準の公開URLは https://ivyak.github.io/study/ です。公開設定後、iPhoneではSafariで開き、必要ならホーム画面に追加します。Scriptableのインストールは不要です。

## 画面と操作

下部バーからクイズ、カレンダー、庭、一覧へ移動します。設定は右上から開きます。iPhoneの画面に合わせ、ヘッダーと下部バーを残して中身だけをスクロールします。開閉と画面の切り替えにはアニメーションがあります。

最初の画面では、全教科から始めるか、教科を選んで始めます。開始するまで問題の出題回数は増えません。クイズは3問ずつ進み、答えを見る前に思い出し、答えを開いたら、思い出せたか、出なかったかを自分で判定します。正解で1コイン増え、ミスでは増えません。

指定した範囲の全問題から、現在の問題の版について思い出せた回数が少ない順に出題します。同じ回数の問題は毎回ランダムに並べ、同じ3問の中では重複させません。未回答とミスだけの問題はいずれも正解0回として扱います。以前の復習予定日にかかわらず、正解回数を優先します。既存の回答履歴とコインは引き継ぎます。

| 状態 | 表示と次の操作 |
| --- | --- |
| 開始前 | 全教科から始める、または教科を指定して始める。 |
| 出題中 | 3問ずつ回答する。今日はここまでで中断できる。教科指定中は全教科に切り替えられる。 |
| 中断後 | 回答した数と思い出せた数を表示する。最初の画面に戻るか、同じ範囲であと3問を始める。 |
| 3問終了後 | 終了を表示する。最初の画面に戻るか、同じ範囲であと3問を始める。 |

中断後と終了後にも、教科指定から全教科へ切り替えられます。最初の画面に戻ってから全教科から始めると、直前に指定した教科に限定されません。途中でアプリを閉じた場合は、開いていた問題と出題範囲を復元します。中断後や終了後に閉じた場合は、その画面を復元します。

原典を見るを開くと、解答の下にPDFページや板書画像が表示されます。画像内のボタンとスライダーで拡大縮小できます。

カレンダーには回答した回数を日別に表示します。回答0回の日は日付だけです。一覧では、教科を選ぶと授業回の箱が並びます。箱を押すと、その回の問題だけを表示する画面へ、ページ全体を読み直さずに移動します。必要な回の問題だけを読み込み、戻るボタンで授業回の一覧に戻れます。この回で学習を押すと、その回に限定して出題します。出題回数、緑の○で正解回数、赤の×でミス回数を表示します。同じ途中の問題を開き直しても出題回数は増えません。

庭は全画面で表示します。右下のガチャから10コインで1回まわせます。全13種類のうち、未入手の動物を均等に抽選し、重複はありません。ラインナップに画像と名前が出るのは入手済みの動物だけです。動物画像と生成プロンプトは [assets/garden](assets/garden/prompts.md) にあります。

## 保存と移行

回答履歴、出題履歴、復習状態、途中の問題、選択した教材、コイン、動物、ガチャの結果を、このブラウザのIndexedDBに保存します。IndexedDBは、ブラウザ内でデータを保持する仕組みです。回答やガチャは保存が完了してから画面に反映します。複数タブの古い記録で、新しい記録を上書きしません。

保存先は端末とブラウザごとに分かれます。端末間の自動同期やアカウント機能はありません。サイトのデータを削除すると記録も消えます。プライベートブラウズは継続利用に使わず、設定の学習記録を書き出すからJSONを保存してください。

学習記録を読み込むでは、確認後に現在の記録を置き換えます。別の端末へ移す場合も、このJSONを使います。前回の保存内容はブラウザ内に残し、現在の記録が壊れた場合は復旧を試みます。どちらも読めない場合は、黙って初期化しません。

Scriptable版から移す場合は、旧版で学習記録を書き出すか、`RecallQuiz/state.json` を取り出して、新しいサイトの設定から読み込みます。回答、コイン、動物を引き継ぎます。旧版の通知とiCloud設定は引き継ぎません。ブラウザ版には通知予約の機能がありません。

同じURLで使っていた旧PCプレビューの記録は初回に引き継ぎます。localhostとGitHub Pagesは保存先が異なるため、移行にはJSONを使います。

教材と画像の取得には通信が必要です。学習記録をサーバーに送る処理はありません。未入手の動物は画面で隠しますが、静的サイトなので画像ファイル自体は公開されます。

## 開発

Node.js 20以上を使います。リポジトリルートで実行します。

```bash
npm ci --prefix apps/recall-quiz
npm run dev --prefix apps/recall-quiz
```

`http://localhost:8766/` を開きます。ソース、教材、動物画像を保存すると再ビルドし、ブラウザを更新します。終了はCtrl+Cです。ポートは `RECALL_QUIZ_PORT=8770` のように変更できます。

URLに `?screen=calendar`、`?screen=garden`、`?screen=catalog`、`?screen=settings` を付けると、対応する画面を直接開きます。

```bash
npm run build --prefix apps/recall-quiz -- --verify-sources
npm test --prefix apps/recall-quiz
npm run test:browser --prefix apps/recall-quiz
npm run preview --prefix apps/recall-quiz
```

ビルドは `output/site/` に公開用ファイルだけを生成します。`preview` はそのフォルダをHTTPで配信します。HTMLファイルを直接開かず、HTTPで確認してください。

| 出力 | 内容 |
|---|---|
| `output/site/index.html` | 画面、JavaScript、CSS、教材一覧。 |
| `output/site/decks/` | 全教材のJSONと一覧。選択した教材や教科を必要なときに読み込む。 |
| `output/site/assets/` | 原典画像、動物画像、アイコン。 |
| `output/site/.nojekyll` | GitHub Pagesでそのまま配信するための指定。 |

特定の教材だけをビルドする場合は、JSONのパスを引数に指定します。通常の公開では、引数を付けず全教材を含めてください。

`--verify-sources` は原資料のSHA-256を確認します。原典画像はPDFページや板書画像からMacで生成し、`.source-cache/` に保存して再利用します。初回生成にはMac、Swift、原資料が必要です。原資料がない場合は、画像キャッシュを用意してハッシュ確認を外すか、`--without-source-images` を指定して原典画像を省きます。その場合は原資料の照合を実施したことにはしません。

数式はビルド時にKaTeXでMathMLへ変換します。外部CDNは使いません。画面テストではChromeを使い、GitHub Pagesと同じサブディレクトリ配信で表示、保存、再読み込み、JSONの読み込みと書き出し、複数タブの競合、ガチャを確認します。iPhone実機のSafariでの確認は別途必要です。

## GitHub Pagesへ公開する

GitHub CLIの認証と、リポジトリのPages設定を変更できる権限が必要です。公開前にビルドと検証を実行します。

```bash
npm run deploy --prefix apps/recall-quiz
```

このコマンドは、`origin` の `gh-pages` ブランチに `output/site/` の内容だけをコミットして送信します。初回はPagesの公開元を `gh-pages` のルートに設定します。既存のPages設定が別の公開元を指す場合は停止します。リポジトリ内のほかの資料や学習記録は公開物に含めません。

更新時も、ビルド後に同じコマンドを実行します。反映には数分かかることがあります。教材を更新するときは問題IDを保ち、内容を変えた問題の版を上げます。学習記録や入手済みの動物は公開更新で初期化しません。

## ファイル構成

| 場所 | 役割 |
|---|---|
| `src/index.html` | 画面の外枠。 |
| `src/style.css` | 配色、配置、アニメーション。 |
| `src/app.js` | 画面と操作。 |
| `src/core.js` | 出題順、集計、コイン、ガチャのルール。 |
| `src/storage.js` | IndexedDBでの保存、競合検出、復旧。 |
| `src/web.js` | 教材の取得、保存との接続、記録の移行。 |
| `decks/` | 問題、解答、判定基準、出典を持つ元JSON。 |
| `assets/garden/` | 動物画像と生成プロンプト。 |
| `scripts/` | ビルド、HTTP配信、Pages公開、画像生成、画面テスト。 |
| `test/` | 出題、保存、移行、ガチャなどのテスト。 |

`output/` と `.source-cache/` は生成物としてGit管理しません。旧版の `Quiz.js` と `.compiled.json` は今後生成しません。
