# スクリーンショットからPDF作成
このツールは、パソコンで表示している画像を切り抜いて保存し、PDF化してまとめることを目的としたアプリケーションです
## できること
- 複数画像のスクリーンショットの自動化
- 切り抜き範囲を指定可能して、画像を一括トリミング
- 画像をPDFにしてまとめる

## 環境
- Python 3.11 以上
- 必要なライブラリ: Pillow, pyautogui

## インストール方法
```bash
pip install pyautogui pillow
```
## 使い方
1. スクショする対象を用意して`screenshot.py`を実行し、終わるまで放置する

    ```bash
    python screenshot.py
    ```
    スクリーンショットの間隔(秒)、ページの枚数を整数値で入力すると、15秒後に撮影が始まります  
    結果は `png_trimming_input` フォルダに保存されます  

2. 「ペイント」等のツールで、トリミングする範囲の四隅の座標を設定する

    「ペイント」では、カーソルを合わせると画面左下に座標が表示されます  

3. `png_trimming.py` を実行してトリミングする

    ```bash
    python png_trimming.py
    ```
    結果は `png_trimming_output` フォルダに保存されます  

4. `png_to_pdf`を実行して、トリミング済みの画像をPDF化する

    ```bash
    python png_to_pdf
    ```
    `output.pdf`が同じ階層のフォルダに保存されます
