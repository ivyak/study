# フォルダのPNGをPDFにまとめる

このリポジトリの `utils/screenshot/png_to_pdf.py` を実行する。スクリプトの複製や、別の変換処理への置き換えは不要。

- 入力はユーザーが指定したフォルダ。未指定ならフォルダのパスを尋ねる。
- フォルダ直下の `.png` / `.PNG` などを対象とし、サブフォルダは走査しない。
- 順序はPythonの `sorted` によるファイル名の昇順（`1.png`, `10.png`, `2.png` の順）。数字の自然順ソートや元画像のリネームは行わない。
- 既存スクリプトと同じく、1画像を1ページにして先頭ページから順につなぐ。複数画像を縦長の1ページに貼り合わせる処理ではない。
- 「PDF名は公共政策論II 第3回」「公共政策論II 第3回.pdfにして」のように名前だけを指定した場合は、入力フォルダ内にその名前で保存する。`.pdf` がなければ付ける。名前の指定には `--name`、保存先のパスまで指定された場合は `--output` を使い、両方を同時に渡さない。
- 出力指定がなければ入力フォルダ内の `output.pdf`。同名ファイルがある場合は `output_2.pdf`、名前指定時なら `指定名_2.pdf` など空いている名前を選び、実際の保存名を報告する。ユーザーが上書きを指示した場合だけ `--overwrite` を使う。元画像は保存する。

リポジトリルートを作業ディレクトリにし、パスを引用符で囲んで実行する（以下は入力・出力を実際のパスに置き換える）。

```bash
.venv/bin/python utils/screenshot/png_to_pdf.py "入力フォルダ" --name "公共政策論II 第3回"
.venv/bin/python utils/screenshot/png_to_pdf.py "入力フォルダ" -o "出力.pdf"
```

依頼例：`$png-to-pdf Kyoto_Univ/[2026後期金２]公共政策論II/第3回 PDF名は「公共政策論II 第3回」`

この例では入力フォルダ内の `公共政策論II 第3回.pdf` に保存する。

`.venv/bin/python` がなければ `python3` を使う。必要な依存は `img2pdf` と `Pillow`。不足する場合はリポジトリの仮想環境を利用・作成してそこにインストールし、システムPythonには入れない。

正常終了と出力PDFの存在を確認し、変換した画像数とPDFへのリンクを返す。PNGが0枚、フォルダが存在しない、画像が壊れている等のエラー時は、成功したと報告せず原因を伝える。
