# ひとつ想起

Scriptableで動く、短い自由想起クイズと動物の庭。頭の中で答え、解答を開いて自己判定します。3問で一区切りにし、1問でも終了できます。画面、数式、原典画像、動物画像は配布ファイルに含まれ、取り込み後はオフラインで使えます。

教材は教科と授業回ごとに管理します。各回10問を上限とし、必要な条件を問題文に含め、紙での計算より知識や解法パターンの想起を中心にしています。

## 画面と操作

画面の移動は下部バーにまとめ、設定は右上から開きます。

| 画面 | できること |
|---|---|
| クイズ | 解答を開き、思い出せたか自己判定する。途中で終了しても記録が残る。 |
| カレンダー | 日ごとの回答回数、表示中の月の回答合計、学習した日数を確認する。 |
| 庭 | 全画面の庭を眺め、右下からガチャとラインナップを開く。 |
| 一覧 | 教科ごとに問題を閲覧し、出題回数、緑の○で正解回数、赤の×でミス回数を確認する。 |
| 右上の設定 | 通知、教材の読み込み、学習記録の書き出し・復元、iCloudバックアップを操作する。 |

iPhone 17を想定した402×874の表示領域を基準にしています。画面全体はスクロールせず、コイン・設定と下部バーを残して中身だけをスクロールします。内容が続く方向の端だけを薄くし、上端・下端に到達した側のぼかしは消します。スクロール不要な画面にはぼかしを出しません。

スクロールの端をさらに引くと中身が少し伸び、指を離すと弾んで戻ります。一覧の解答、補足、原典画像などは縦にスライドして開閉します。端末で動きを減らす設定が有効な場合は、これらの動きと動物のアニメーションを止めます。

ガチャのパネルは内容に合わせて高さを変えます。長いラインナップは上限の高さで止め、パネルの中身だけをスクロールします。

## iPhoneで始める

1. [Scriptable](https://apps.apple.com/jp/app/scriptable/id1405459188)をインストールする。
2. Macで作った `output/Quiz.js` をiPhoneへ渡す。iCloud DriveのScriptableフォルダへコピーするか、Scriptableで新規スクリプトを作り、全文を貼り付けて `Quiz` と命名する。
3. Scriptableで `Quiz` を実行する。
4. 通知を使う場合は、右上の設定で昼の時刻を選び、昼の通知をONにして保存する。初期値はOFF、時刻は12:30。
5. 1分後の通知をテストを押し、アプリを閉じて通知とタップ後の起動を確認する。

日々の利用にMacの起動やSSH接続は不要です。通知はiOSへ予約します。集中モード、通知要約、通知許可の設定によって表示時刻は変わります。

同じスクリプトを複数同時に開かないでください。更新時は画面を閉じ、同じ `Quiz` を置き換えます。学習記録の保存先はスクリプト名に依存しません。

## アプリと教材を更新する

| 渡すファイル | 使う場面 | iPhoneでの操作 |
|---|---|---|
| `output/Quiz.js` | 画面、ガチャ、報酬、動物画像などのアプリ更新。 | Scriptableの同じスクリプトを置き換える。 |
| `output/<deck-id>.compiled.json` | 教材の追加や問題の更新。 | 右上の設定から教材を読み込む。 |

`decks/` にある元のJSONではなく、ビルド済みの `.compiled.json` を取り込みます。読み込んだ教材は端末内に保持し、一覧から学習する教材を切り替えられます。選択中の教材には、同じ画面に戻るためのボタンを置いていません。

教材を指定しないビルドでは、PCプレビューに `decks/` の全教材が並び、それぞれの `.compiled.json` を生成します。`Quiz.js` に同梱する教材は `calc2-lesson01` です。iPhoneでほかの教材を使うには、対応する `.compiled.json` を取り込んでください。教材を指定してビルドした場合は、その教材を `Quiz.js` に同梱します。

PCで編集した内容は、取り込み済みのiPhoneへ自動では反映されません。アプリを更新した場合は `Quiz.js` も取り込み直してください。教材の切り替えや更新で、回答履歴、コイン、動物を初期化しません。

## クイズと復習

解答を開いた後、思い出せたを押すと正解、出なかったを押すとミスとして記録します。読んで納得しただけの場合は、出なかったを選びます。回答の入力や自動採点はありません。

正解の自己判定で1コイン増えます。ミスでは増えません。更新前に持っていたコインは減らさず、新しい回答からこのルールを適用します。

解答の下の原典を見るを開くと、その場にPDFページや板書画像を表示します。＋・−ボタンとスライダーで50〜300%に拡大縮小し、全体で100%へ戻します。拡大後は画像内を上下左右にスクロールできます。

初回の正解は翌日、別の日にも正解すると3・7・14・30日へ復習間隔が進みます。同じ日の正解だけで間隔を延ばしません。ミスは翌日と、少なくとも他の2問を挟んだ当日の再確認候補になります。当日の再確認は各問題1回までです。

これは試作用の単純な復習ルールです。FSRSや、試験日から逆算する機能はありません。短答クイズとは別に、計算や証明の演習も行う前提です。

## カレンダーと問題別の記録

カレンダーは、自己判定を終えた時点で1回と数えます。同じ問題の復習も含みます。回答0回の日の枠には日付だけを表示し、点や0回の表示は入れません。日付を押すと、その日の回答回数を確認できます。

一覧の出題回数は、問題を開いた時点で記録します。同じ途中の問題を開き直しても増えません。問題を押すと、解答と正解の判定基準が開きます。

問題の版が変わっても、同じ問題IDの回数は過去の回答と合算します。旧版では未回答の出題を保存していなかったため、その期間の出題回数は回答済みの記録から集計します。教材更新で除かれた問題も、旧版の問題として回数を確認できます。

## 庭とガチャ

ガチャは1回10コインです。全13種類のうち、未入手の動物から均等に1種類を抽選します。重複はありません。10コイン未満のときと、全種類がそろったときは、ガチャを回せません。

ラインナップでは、入手済みの動物だけ画像と名前を表示します。動物を押すと、大きな画像と説明を開きます。未入手の枠は疑問符と番号だけで、画像や名前を表示しません。

入手した動物は庭で跳ねたり、移動したり、体を揺らしたりします。動物をタッチすると、小さく反応して名前が出ます。旧版の芽、花、木の購入記録は、それぞれうさぎ、きつね、しかとして引き継ぎます。

抽選結果とコインの消費は一緒に保存し、同じ操作を再送しても二重に消費しません。アプリ更新で入手済みの動物や残高を消すことはありません。

動物は組み込みの画像生成で作った透過PNGです。[画像と生成プロンプト](assets/garden/prompts.md)を保存し、ビルド時に `Quiz.js` へ埋め込みます。iPhoneで動物画像を別に読み込む必要はありません。

## 保存とバックアップ

保存先はScriptableのローカルdocuments領域にある `RecallQuiz/` です。

| ファイル | 内容 |
|---|---|
| `state.json` | 回答・出題履歴、復習状態、コイン、動物、ガチャの結果、設定、途中の問題。 |
| `state.pending.json` | 保存途中の記録。 |
| `state.backup.json` | 前回の保存内容。 |
| `decks.json` | 読み込んだ教材の一覧と内容。 |
| `deck.json` | 選択した教材。旧版の教材を引き継ぐ際にも使用する。 |

1問ごと、ガチャ1回ごとに保存し、保存の応答後に画面を更新します。壊れた記録を黙って初期化せず、保存途中の記録や前回のバックアップから復元を試みます。

設定の学習記録を書き出すから、`state.json` の内容をJSONとして書き出せます。学習記録を復元するでは、確認後に記録を置き換えます。通知設定は現在の端末のものを維持します。書き出しにはコイン、動物、ガチャの結果も含みますが、教材ファイルは含みません。

iCloudバックアップをONにすると、本体への保存後にScriptableのiCloud領域にある `RecallQuizBackup/state.json` へコピーします。同期完了の保証や、複数端末での同時編集には使いません。端末故障やアプリ削除に備え、教材ファイルも別に保管してください。

## Macで編集する

Node.js 20以上を使います。リポジトリルートから、初回に依存関係を準備します。

```bash
npm ci --prefix apps/recall-quiz
```

編集用のプレビューを起動します。

```bash
npm run dev --prefix apps/recall-quiz
```

`http://localhost:8766/` を開きます。`src/`、`decks/`、ビルドスクリプトを保存すると再ビルドし、ブラウザを自動更新します。ビルドエラーはプレビューに表示します。`assets/garden/` を変更した場合は、手動でビルドし直すか、プレビューを再起動してください。終了はCtrl+Cです。

| 開きたい画面 | URL |
|---|---|
| クイズ | `http://localhost:8766/` |
| カレンダー | `http://localhost:8766/?screen=calendar` |
| 庭 | `http://localhost:8766/?screen=garden` |
| 一覧 | `http://localhost:8766/?screen=catalog` |
| 設定 | `http://localhost:8766/?screen=settings` |

ポートを変える場合は、`RECALL_QUIZ_PORT=8770 npm run dev --prefix apps/recall-quiz` のように指定します。PCプレビューの履歴はブラウザ内に保存し、iPhoneの記録とは同期しません。通知やファイル選択などの端末操作はScriptable版で確認します。

## ビルドと検証

全教材のPCプレビューと、iPhone向けファイルを生成します。

```bash
npm run build --prefix apps/recall-quiz -- --verify-sources
npm test --prefix apps/recall-quiz
npm run test:browser --prefix apps/recall-quiz
```

特定の教材だけをビルドする場合は、元のJSONを指定します。

```bash
npm run build --prefix apps/recall-quiz -- apps/recall-quiz/decks/calc2-lesson01.json --verify-sources
```

| 出力 | 用途 |
|---|---|
| `output/Quiz.js` | Scriptableへ取り込むアプリ。動物画像も同梱する。 |
| `output/<deck-id>.compiled.json` | iPhoneで追加・更新する教材。 |
| `output/preview.html` | PCで開くプレビュー。 |

`--verify-sources` は原資料のSHA-256を確認します。原典画像は、PDFの参照ページやPNG・JPEGの板書画像からMacで生成し、`.source-cache/<sha256>/` に保存して再利用します。初回生成にはMac、Swift、原資料が必要です。原資料が変わった場合は、問題と出典を確認し直してから更新します。

原資料がない環境でも、キャッシュがあれば `--verify-sources` を外してビルドできます。原資料もキャッシュもない場合は、`--without-source-images` を指定すると原典画像を省けます。その場合、原資料の照合や原典画像の同梱を実施したことにはしません。

KaTeXはビルド時の数式変換に使い、生成したMathMLをアプリで表示します。Playwrightの画面テストにはChromeを使います。一時プロファイルで外部HTTP通信を遮断し、スマホ幅、中央だけのスクロール、開閉アニメーション、数式、コイン、ガチャ、保存後の再読み込みなどを確認します。

## ファイル構成

| 場所 | 役割 |
|---|---|
| `src/index.html` | ヘッダー、下部バー、共通の外枠。 |
| `src/style.css` | 配色、配置、アニメーション。 |
| `src/app.js` | クイズ、カレンダー、庭、ガチャ、一覧、設定の画面と操作。 |
| `src/core.js` | 出題、復習、集計、正解報酬、ガチャのルール。 |
| `src/storage.js` | 保存、バックアップ、破損時の復旧。 |
| `src/scriptable.js` | iOSの通知、教材の取り込み、WebViewとの受け渡し。 |
| `decks/` | 問題、解答、判定基準、出典を持つ教材の元JSON。 |
| `assets/garden/` | 動物画像と生成プロンプト。 |
| `scripts/` | ビルド、開発プレビュー、原典画像の生成、画面テスト。 |
| `test/` | 出題・保存・ガチャなどのテスト。 |

`src/index.html` はビルド前のテンプレートなので、直接開かずプレビューを使います。`output/` と画像キャッシュは生成物としてGit管理しません。

## iPhoneでの確認状況

PCのロジックテストとタッチ操作を模擬した画面テストは実施しています。iPhoneのScriptable実機で確認した結果ではありません。実機では次の操作を確認する必要があります。

- ロック中の通知、通知タップでの起動、時刻変更、通知OFF。
- 1問での終了、答え表示後の中断・復帰、回答直後の終了。
- 画面の高さ、端末上下の余白、原典画像の拡大、スライド開閉、端で引っ張る操作。
- 正解時だけのコイン加算、ガチャの消費、入手済みの表示、再起動後の保持。
- 機内モードでの数式、原典画像、動物の表示。
- 教材の追加・更新、学習記録の書き出し・復元、iCloudバックアップ。
