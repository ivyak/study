初回の講義の演習のプログラム例約4分

原典：p. 2

例題：次のそれぞれを、単精度、倍精度で計算せよ。

\[0.1+0.2+0.3+\cdots+0.9+1.0\]
\[0.01+0.02+0.03+\cdots+0.99+1.00\]

・倍精度

#include <stdio.h>

int main(){

  float x, dx, sum; /* 倍精度で実行するときは float を double にせよ */
  sum = 0;
  dx = 0.1;

  for( x = 0; x <= 1; x += dx )
    sum += x;

  printf( "%g\n", sum );

  return 0;
}
import numpy as np

sum = 0
x = 0.1

while x <= 1:
    sum += x
    x += 0.1

print(f"{sum:.6f}")

・単精度

import numpy as np

sum = np.float32(0)
x = np.float32(0.1)

while x <= np.float32(1):
    sum = np.float32(sum + x)
    x = np.float32(x + np.float32(0.1))

print(f"{sum:.6f}")

プログラム中の0.1をすべて1, 0.01等に変えて実行し、結果を検討せよ。

ガウスの消去法と軸選択約4分

問：10進3桁のガウスの消去法約3分

原典：p. 4–p. 5 上部の板書写真

10進3桁で

\[\begin{cases}1.00\times10^1x+1.00\times10^5y=1.00\times10^5,\\1.00x+1.00y=2.00.\end{cases}\]

軸選択つきガウスの消去法で計算すると何が起きるか、考えよ。

前回のアルゴリズム

\[\begin{cases}1.00\times10^1x+1.00\times10^5y=1.00\times10^5,\\1.00x+1.00y=2.00.\end{cases}\quad \text{第1式を }-10^{-1}\text{ 倍して第2式へ}\]
\[\begin{cases}1.00\times10^1x+1.00\times10^5y=1.00\times10^3,\\0+(1-10^4)y=2-10^4.\end{cases}\]

第1式の右辺の指数は原文どおり（上では5、下では3）。

\[\begin{aligned}\therefore\quad -9999y&=-9998,\\\therefore\quad -1.00\times10^4y&=-1.00\times10^4,\\\therefore\quad y&=1.00.\end{aligned}\]

p. 5上部の板書写真（以下は写真中の記号）。

\[(-9999y=-9998),\qquad -1.00\times10^4y=-1.00\times10^4\ \longrightarrow\ \boxed{y=1.00}\]
\[1.00\times10^1x=0\ \longrightarrow\ \boxed{x=0.00}\]
\[-9999y=998,\qquad -1.00\times10^4y=-9.98\times10^2,\qquad \boxed{y=9.98\times10^2}\]

写真右端の式は原文どおり。中央の \(10^2\) は右辺の下に書かれている。

対処方法：部分pivotingとfull pivoting約1分

原典：p. 5 中部–下部

前回説明した列方向に要素の絶対値の最大値を探すだけでなく、行方向（つまり全ての成分）にも最大値を探索する。

列方向：部分pivoting。行方向（つまり全ての成分）にも探索：full pivoting。

通常は（計算時間の節約のため）部分pivotingを用いる。

§2.2 定常反復解法約14分

微分方程式の境界値問題約2分

原典：p. 6

そもそも連立方程式をときたいのはどういう時？

→ 微分方程式の境界値問題

例　Find \(u(x),\ 0<x<1\), s.t.

\[\begin{cases}-u^{\prime\prime}(x)+au(x)=f(x),\\u(0)=u(1)=0.\end{cases}\]

cf. 微分方程式の初期値問題

\[\begin{cases}-u^{\prime\prime}(x)+au(x)=f(x),\\u(0)=0,\\u^{\prime}(0)=0.\end{cases}\]

これを解くために \(0<x<1\) 区間を \(N\) 等分して、\(h=1/N,\ x_j=jh\) とおき、\(u(x_j)=U_j\) とすると、

中心差分と連立一次方程式約3分

原典：p. 7–p. 8 冒頭

\[\begin{aligned}u(x+h)&\simeq u(x)+u^{\prime}(x)h+\frac12u^{\prime\prime}(x)h^2,\\u(x-h)&\simeq u(x)-u^{\prime}(x)h+\frac12u^{\prime\prime}(x)h^2.\end{aligned}\]
\[u(x+h)+u(x-h)\simeq2u(x)+u^{\prime\prime}(x)h^2\]
\[\therefore\quad u^{\prime\prime}(x)\simeq\frac{u(x+h)-2u(x)+u(x-h)}{h^2}\quad\text{（中心差分という）}\]

微分方程式を \(x=x_j\) で考え、中心差分を適用すると、

\[-\frac{U_{j+1}-2U_j+U_{j-1}}{h^2}+aU_j=f(x_j)\]
\[1\le j\le N-1\quad\text{かつ}\quad U_0=U_N=0\]

これは次の連立一次方程式を表す。

\[\begin{pmatrix}2+ah^2&-1&&&0\\-1&2+ah^2&-1&&\\0&-1&2+ah^2&-1&\\&&\ddots&\ddots&-1\\0&&&-1&2+ah^2\end{pmatrix}\begin{pmatrix}U_1\\U_2\\\vdots\\\vdots\\U_{N-1}\end{pmatrix}=h^2\begin{pmatrix}f(x_1)\\f(x_2)\\\vdots\\\vdots\\f(x_{N-1})\end{pmatrix}\]

このような「行列の成分が殆ど0」（疎行列）を念頭において考える。

ヤコビ法（Jacobi法）約2分

原典：p. 8（冒頭を除く）

例

\[\begin{cases}4x+y=6,\\x+2y=5.\end{cases}\]

① 各変数について整理する。

\[x=\frac14(6-y),\qquad y=\frac12(5-x)\]

② 左辺に \(k+1\)、右辺に \(k\) を付ける。

\[x_{k+1}=\frac14(6-y_k),\qquad y_{k+1}=\frac12(5-x_k)\]

③ \(x_0,y_0\) を適当に決める。

これをヤコビ法（Jacobi法）という。

片方の変数の更新時にもう片方を待たなくてよくなる。

\[\begin{array}{c|ccccc}k&0&1&2&3&5\\\hline\binom{x_k}{y_k}&\binom00&\binom{1.5}{2.5}&\binom{0.875}{1.75}&\binom{1.0625}{2.0625}&\binom{1.00781}{2.00781}\end{array}\]

原典では \(k=3\) と \(k=5\) の間に「4」の表示があるが、ベクトル値は記載されていない。

テイラー展開のときに \(\simeq\) してるので、細かい桁を求めても意味がない。↓ \(k=5\) の値。

ガウス・ザイデル法（Gauss–Seidel法）と収束の問い約2分

原典：p. 9

例

\[\begin{cases}4x+y=6,\\x+2y=5.\end{cases}\]

① 各変数について整理する。

\[x=\frac14(6-y),\qquad y=\frac12(5-x)\]

② 左辺に \(k+1\)、右辺に \(k\) を付ける。

\[x_{k+1}=\frac14(6-y_k),\qquad y_{k+1}=\frac12(5-x_{k+1})\]

③ \(x_0,y_0\) を適当に決める。

これをガウス・ザイデル法（Gauss–Seidel法）という。（少ない \(k\) で終了する。）

\[\begin{array}{c|cccc}k&0&1&2&3\\\hline\binom{x_k}{y_k}&\binom00&\binom{1.5}{1.75}&\binom{1.0625}{1.96875}&\binom{1.00781}{1.99609}\end{array}\]

テイラー展開のときに \(\simeq\) してるので、細かい桁を求めても意味がない。↓ \(k=3\) の値。

疑問

Jacobi法、Gauss–Seidel法が収束する条件は？

収束するとは？ → ベクトルがベクトルに収束する。

ベクトルの大きさ、ベクトルとベクトルの距離を測るには「ノルム」を用いる。

定義：ノルムとその例約2分

原典：p. 10 前半–中部

\(V\)：ベクトル空間、\(\|\cdot\|:V\longmapsto\mathbb R\) について、写像 \(\|\cdot\|\) がノルム（norm）

\[\overset{\mathrm{def}}{\Longleftrightarrow}\quad\begin{cases}(1)\ \forall x\in V,\ \|x\|\ge0,\quad\text{特に}\ \|x\|=0\iff x=0,\\(2)\ \forall\alpha\in\mathbb C,\ \forall x\in V,\ \|\alpha x\|=|\alpha|\cdot\|x\|,\\(3)\ \forall x,y\in V,\ \|x+y\|\le\|x\|+\|y\|\quad\text{（三角不等式）}.\end{cases}\]

例　\(x=(x_1,\ldots,x_n)\in\mathbb C^n\)

\[\begin{aligned}(1)\quad \|x\|_1&=|x_1|+|x_2|+\cdots+|x_n|,\\(2)\quad \|x\|_2&=\left(|x_1|^2+|x_2|^2+\cdots+|x_n|^2\right)^{1/2},\\(3)\quad \|x\|_\infty&=\max\{|x_1|,|x_2|,\ldots,|x_n|\}.\end{aligned}\]

定義：ノルムでの収束／演習／事実約2分

原典：p. 10 下部–p. 11

定義　\(\{x_k\}\subset V,\ x_*\in V\) のとき、

「\(x_k\) が \(x_*\) に \(\|\cdot\|\) で収束する」

\[\overset{\mathrm{def}}{\Longleftrightarrow}\quad\lim_{k\to\infty}\|x_k-x_*\|=0\]

実数値としての極限。

演習

上の例の(1)〜(3)がノルムであることを示せ。

事実　\(\mathbb C^n\)

\(\mathbb C^n\) の任意のノルム \(\|\cdot\|_a,\|\cdot\|_b\) に対して、

\[\exists c,C>0,\quad\forall x\in\mathbb C^n,\quad c\|x\|_a\le\|x\|_b\le C\|x\|_a\]

→ この意味はレポート①で考える。

「事実」の文と不等式はp. 11の板書写真から清書。
