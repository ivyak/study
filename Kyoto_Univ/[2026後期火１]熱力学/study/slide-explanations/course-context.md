## 原典と補足を区別した点

| 位置 | 原典・口頭説明 | 解説での扱い |
|---|---|---|
| p.1 | 「理想的，定容」「実在の系，定圧」、口頭ではエネルギー低下の向きに言及 | Fは実在系にも使える。F/G減少の判定には温度とV/pの固定・物質の出入り・非膨張仕事の条件を補う |
| p.4〜6 | CO₂の7 MPa、Heの15→7.5 MPa | 7 MPaは概略値。Heの半減は一定T,Vの理想気体近似で説明。共存圧力の維持には温度一定と平衡への復帰を付す |
| p.7 | CO₂等温線と手書きの水平部 | 単相のpV一定と二相共存を区別。C→Eは圧縮時の液化、E→Cは膨張時の気化 |
| p.8〜10 | Fが自由度、Pが相数。一方相図のPは圧力 | 原式を保持して別意味を明記し、補足ではf,r,pへ分離。相律の量に相の割合は含めない |
| p.10 | 氷と水の「自由エネルギー（化学ポテンシャル）」が等しい | 総Gではなく純物質のμ=G/nを比較。口頭の物質量で割る説明を反映 |
| p.11 | 第0法則と高温→低温の図が同ページ | 第0法則は熱平衡の推移関係、移動の向きは第2法則に関わる補足として分離 |
| p.12〜13 | 一定Cでの熱量 | 熱容量の一定性、外界への熱損失と仕事を無視する条件を追加 |
| p.17 | w=-∫P dV | 一般には外圧を積分。系の圧力で置換する条件を補足 |
| p.18 | nRTを積分の外に出すが、等温の語は本文にない | 文字起こし終盤の温度一定と断熱の対比を採用。物質量一定・可逆等温の条件を明記 |
| p.19〜21 | dU/dT、dH/dT、Cp=CV+R | 固定変数を付した偏微分を補足。全体なら差はnR、モル当たりならRと分離 |
| p.20 | Hを内部エネルギーに熱膨張を加えたものと案内 | 定義U+pVと、定圧・膨張仕事のみでのq=ΔHを区別 |
| p.22 | 比熱・熱容量・モル熱容量 | 単位とC=mc=nCmを追加。物質量の前提省略に注意する口頭説明を反映 |
