01

⑤ 大数の法則

条件まで理解IMG_3519 · 中央の仮定 → 右の結論

独立で同じ分布に従う実数値の確率変数 X1,X2,… を考えます。板書では、平均と分散を E[X1]=μ、V(X1)=σ2<∞ と置いています。

X―n=1n∑k=1nXk

これは n 個の観測の平均です。観測のたびに値が変わるので、標本平均 X―n 自体も確率変数です。

∀ε>0,limn→∞P(|X―n−μ|>ε)=0

どんな正の許容誤差 ε を先に固定しても、標本を増やせば、その誤差を超えて平均から外れる確率は 0 に近づきます。これを確率収束といい、X―n→Pμ と書きます。

補足 / ε は固定してから n を増やす「必ず誤差がなくなる」「毎回、前より近くなる」という主張ではありません。板書の主張は大数の弱法則です。
補足：なぜ平均を取ると、ばらつきが小さくなる？

期待値の線形性と独立性から、

E[X―n]=μ,V(X―n)=1n2∑k=1nV(Xk)=σ2n

独立性によって異なる標本間の共分散が 0 になります。さらにチェビシェフの不等式を使うと、

P(|X―n−μ|>ε)≤σ2nε2⟶0

これが有限分散という仮定の下での短い証明です。板書にない理解補助として追加しています。

02

⑥ 中心極限定理

条件・意味を理解IMG_3520 · 左の近似 → 中央の標準化 → 右の極限

独立・同分布という仮定は⑤と同じです。ここでは σ で割るため、0<σ2<∞ が必要です。平均の誤差を、その標準偏差 σ/n を単位として測ります。

Zn=n(X―n−μ)σ=X―n−μσ/n

平均を引いて中心を 0 に移し、標準偏差で割って幅をそろえる操作が標準化です。E[Zn]=0、V(Zn)=1 は、すべての n で成り立ちます。

標準化した分布が、標準正規分布に近づく

Z~N(0,1) とすると、任意の固定した実数 a<b について、

limn→∞P(a<Zn<b)=P(a<Z<b)=12π∫abe−x2/2dx

これを分布収束といい、Zn→dN(0,1) と書きます。平均 0・分散 1 というだけでは正規分布とは限りません。「区間に入る確率まで近づく」ことが定理の内容です。

補足 / なぜ √n 倍するのか標本平均の標準偏差は σ/n。誤差をそのまま眺めると 0 へ縮むので、n 倍して、残るゆらぎの形を見ます。

板書の「正規分布で近似できる」の読み方

X―n ~approx. N(μ,σ2n)

N(μ,σ2/n) の第2引数は分散です。これは大きな n に対する近似表現で、厳密な極限の主張は上の Zn の式です。

補足：近似と厳密な等式を区別する

元の Xk が正規分布なら、標本平均も任意の n で厳密に正規分布です。一般の分布では近似であり、十分な標本数は元の分布や求める精度に依存します。σ=0 なら各 Xk=μ が確率1で成り立ち、この標準化はできません。

03

具体例：公平なコイントス

計算を再現IMG_3521 · 左の確率 → 右上 LLN → 右下 CLT

独立なコイントスで、表を 1、裏を 0 とします。板書の設定は P(X1=1)=P(X1=0)=1/2。X―n は n 回のうち表が出た割合です。

P(X―n=kn)=(nk)12n,k=0,1,…,n

表が k 回となる並び方は (nk) 通りで、どの並びも確率 2−n。この2つを掛けたのが板書の式です。ここで μ=1/2 です。

右上の図：LLN

標本平均は 1/2 の近くに集まり、固定した幅 ε の外に出る確率が小さくなります。横軸は平均そのものです。

右下の図：CLT

中心を引き、幅を拡大すると正規分布の形が現れます。区間 [a,b] の棒の確率の和が、曲線下の面積に近づきます。

補足 / 板書の山の形は模式図有限回のコイントスで平均が取る値は 0,1/n,…,1 だけです。滑らかな山は形を伝える図で、実際の分布は離散的です。標準化の正確な倍率は次節の 2n です。
