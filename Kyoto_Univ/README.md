# 授業ノートのポータル

[index.html](index.html) をブラウザで開くと、学期別の時間割から授業を選べます。授業回の行を押すと、近くに資料メニューが開きます。
各教科の講義回ページは、元の文章・数式・図・操作を保ったままLIFEの共通UIで表示します。各資料の「＜」からその教科の一覧に戻れます。
ポータルの閲覧は、HTMLを直接開いてもできます。各資料が外部サービスを使っている場合、その表示にはネット接続が必要です。

授業一覧の「武器一覧」「演習問題」「過去問」から、教科ごとのページを開けます。武器一覧・演習問題には、該当する名前の既存資料を表示します。資料がない場合は灰色になり、押せません。過去問は未検索・資料なしでも開けます。

## 過去問検索を画面から実行する

リポジトリのルートで次を実行し、表示されるURLを開いてください。

```bash
python3 Kyoto_Univ/serve_portal.py
```

既定のURLは `http://127.0.0.1:8765/index.html` です。過去問ページで担当教員のファイル名表記と授業年度を指定し、「検索スキルを実行」を押します。教員名は必須で、未入力や空白だけの状態では画面・サーバーの両方で開始できません。インストール済みの `kyoto-past-exams` の一覧収集・検索を実行し、Codex CLIが候補の内容確認と報告を続けます。ネット接続と、利用できるCodex CLIの認証が必要です。

未検索の過去問ボタンは白色、検索を実行したボタンは金色です。ファイル名だけから「同名教科・同名教員・前年度」「同名教科・同名教員・前年度よりも前」「同名教科・違う名前の教員」の3条件を照合します。教員名を推測で補いません。

内容はDriveのプレビューで確認し、「問題」「講義資料」「解答」「演習問題」のバッジを付けます。未読・プレビュー不能は「未確認」です。結果の一覧はファイル名（タイトル名）・資料の種類・URLの3列だけで、資料自体はダウンロードしません。走査できなかった領域はDrive上の階層パスとURLを一番下にまとめます。親フォルダの直下を走査できない場合は、その親フォルダだけを表示します。

一覧収集は1回200ページの上限に達しても、未巡回が残れば自動で再開します。取得の進展がなくなった場合は終了し、未走査・取得失敗を残します。未走査・全件取得未確認を「なし」と判定しません。

一覧・判定・内容の根拠は各教科の `study/past_exam_search.json`、リンク一覧は `study/past_exam_search.md` に保存します。旧形式の結果も新しい3列表示へ移行し、以前に保存したPDFは残します。現在の検索処理は資料のダウンロード・配置確認を行いません。

## 資料を追加・移動したとき

授業フォルダ内に `.html` または `.htm` ファイルを置き、次を実行してください。

```bash
python3 Kyoto_Univ/update_portal.py
```

実行後、ポータルを再読み込みすると一覧に反映されます。ブラウザを開くだけではフォルダ内の変更は自動取得しません。

- 時間割を含む名前の直下フォルダを授業として扱い、その下のサブフォルダも検索します。`ui` は授業に含めません。
- `[2026後期木３]授業名` 形式から授業名・時間割を読み取り、曜日・時限順に表示します。
- 資料名はHTMLの `p.subtitle`、`title`、ファイル名の順に使用します。
- HTML資料がない授業も一覧に表示します。
- 名前から自動分類されない資料は、教科フォルダの `study/resources.json` に `{"practice": ["授業資料/EXmathofstrings2026.pdf"]}` のように教科フォルダからの相対パスを記載すると、演習問題に登録できます。武器一覧は `weapons` キーを使います。
- 更新スクリプトはLIFE形式の資料の共通サイドバーを同期し、相対リンクで開きます。
- 講義回はHTMLの `study-lesson` メタ情報、またはファイル名の「第N回」から読み取ります。講義回が不明な資料は「関連資料」に表示します。
- `study-kind` メタ情報で「解説」「要約」「理解度クイズ」「対応問題」を指定できます。未作成の項目は開けません。
- 金の四角14個は、各回にHTML資料があるかを表します。その横の緑・紫・赤の四角は、それぞれ武器一覧・演習問題・過去問の有無です。各色の枠は常に表示し、資料があると塗りつぶします。過去問は、保存された検索結果でこの科目の試験問題を根拠付きで確認した場合に赤を塗りつぶします。枠のみの場合、未発見と未確認の詳細は過去問ページで区別できます。過去問ページは資料の種類とDriveリンクを表示します。
- 作成日は `study-created` メタ情報があるときだけ表示し、不明な日付は `—` にします。

`index.html` は生成ファイルです。共通のデザイン・操作は `ui/life.css` と `ui/life.js`、ポータルの構造は `ui/portal.html`、共通サイドバーは `ui/shell.html` で管理します。テンプレートや資料情報を変えたときは、更新スクリプトを再実行してください。`ui/mock.html` はデザイン確認用のモックです。
