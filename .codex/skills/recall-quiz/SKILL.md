# Recall Quiz

習った範囲を短時間で思い出すための教材を作る。選択式の問題や、長い計算をその場で完遂させる問題は既定にしない。問題作成はMac、出題・記録・通知はiPhoneのScriptableアプリが担当する。

## 教材の作成・更新

- 科目と授業回・学習済み範囲を特定する。最初の試作は1授業回、15問以内を目安にし、ユーザーの指定があれば従う。リポジトリ全PDFを一括処理しない。
- 既存解説で候補を拾い、答えと条件は講義の原資料で照合する。数式・手書きはページ画像を確認する。問題の正しさは原資料、優先度は利用可能な演習・過去問を基準にする。確認していない試験頻出度や配点は付けない。
- 1問1判断を狙い、問いと答えを短くする。型の識別、解法の第一手、適用条件、例外、検算も含める。短くするために必要な仮定を落とさない。
- 「この内容が言えれば正解」という短い判定基準を付ける。補足は別欄に置く。答えの見た目を覚えるだけの重複問題を増やさない。
- 既存デッキの `sourceManifest` のハッシュと照合済みページを先に確認する。同じ資料は既存の問題・照合記録を再利用する。資料が変わったら影響範囲を読み直してから問題とハッシュを更新する。ハッシュの一致だけで初回の内容照合を済ませたことにしない。
- [データ仕様](references/deck-format.md)に従い、リポジトリの `apps/recall-quiz/decks/` にJSONを保存する。既存の内容修正は固定IDを保つ。問い・答え・正解基準などが変われば問題の `version` とデッキの `version` を上げる。別の判断を問う問題には新IDを付ける。IDを並び順から再採番しない。
- 学習履歴やコインを教材の更新で初期化しない。ユーザーが誤答記録を渡した場合は、まず曖昧な問い・前提理解不足・条件の欠落を点検し、単に問題数を増やさない。

## ビルドと引き渡し

リポジトリルートから実行する。初回のみアプリの依存関係を `npm ci --prefix apps/recall-quiz` で準備する。

```bash
npm run build --prefix apps/recall-quiz -- apps/recall-quiz/decks/<deck-id>.json --verify-sources
npm test --prefix apps/recall-quiz
```

ビルドは数式をオフラインで表示できるMathMLへ変換し、画面・問題・参照先のPDFページ画像を `apps/recall-quiz/output/Quiz.js` にまとめる。原典画像はMacで生成し、原PDFのハッシュとページでキャッシュを再利用する。初回生成には原PDFとSwiftが必要。原資料のハッシュ、ページ参照、数式に問題があれば修正して再実行する。PDFが手元にない場合は照合未実施を明示し、ハッシュ確認を通過したと報告しない。画像なしの配布を選ぶ場合だけ `--without-source-images` を指定する。

- 初回配布は `Quiz.js`、教材だけの更新は `<deck-id>.compiled.json`。iPhoneでの操作は[アプリの手順](../../../apps/recall-quiz/README.md)を参照する。
- PCプレビューで問題・解答・数式・原典画像のページ対応と拡大・終了導線を確認する。PCのプレビュー記録はiPhoneとは別であり、実機の通知・保存の検証に代用しない。
- 変更の範囲、問題数、出典、未確認の範囲、取り込み対象を短く伝える。iPhoneの実機を操作していなければ、通知や中断復帰を実機確認済みとしない。

画面だけの変更では教材を作り直さない。教材作成だけの依頼で、公開ホスティング・通知送信サービス・アカウント設定を追加しない。
