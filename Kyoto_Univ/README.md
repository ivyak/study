# 授業ノートのポータル

[index.html](index.html) をブラウザで開くと、正方形の教科カードから授業フォルダ内のHTML資料を閲覧できます。各資料の「授業一覧に戻る」リンクからポータルに戻れます。
ポータル自体はネット接続・サーバー・追加ライブラリなしで動作します。各資料が外部サービスを使っている場合、その表示にはネット接続が必要です。

## 資料を追加・移動したとき

授業フォルダ内に `.html` または `.htm` ファイルを置き、次を実行してください。

```bash
python3 Kyoto_Univ/update_portal.py
```

実行後、ポータルを再読み込みすると一覧に反映されます。ブラウザを開くだけではフォルダ内の変更は自動取得しません。

- 直下のフォルダを授業として扱い、その下のサブフォルダも検索します。
- `[2026後期木３]授業名` 形式から授業名・時間割を読み取り、曜日・時限順に表示します。
- 資料名はHTMLの `p.subtitle`、`title`、ファイル名の順に使用します。
- HTML資料がない授業も一覧に表示します。
- 元の資料は変更せず、相対リンクで開きます。

`index.html` は生成ファイルです。ポータルのデザインや構成を変える場合は、`update_portal.py` を編集して再実行してください。
